## 3D の作り方（今回の主題）

```
   3D の点 (x, y, z)
     ↓ 回転 ―― x・y・z 軸まわりの 2D 回転を 3 回
     ↓ 透視投影 ―― 遠いものは小さく：x' = CX + FOCUS × x / z
     ↓ 128 × 80 のドット画面
```

3D を感じさせる 4 つの手がかりを全部入れた。

| 手がかり | どう作ったか |
|---|---|
| **遠近** | `project()`：z で割る。近づくほど大きく、真ん中から離れる |
| **視差** | 星は全部同じ速さで動くが、近い星ほど画面上で速く流れる（割り算の結果） |
| **隠面** | こちらを向いていない面は描かない（法線と視線の内積）。残った面は奥から順に塗る（画家のアルゴリズム） |
| **陰影** | 面の法線と光の向きの内積で明るさを決める |

## 3D っぽさを足したもの（2 回目）

| 足したもの | 何が変わるか |
|---|---|
| **カメラが自機を追って傾く** | 曲がると画面全体が傾き、カメラが少し遅れて横についてくる。「自分がそこにいる」感 |
| **トンネルの輪** | 等間隔の輪が手前へ流れる。奥行きと速さが**測れる**ようになる（遠近法の線） |
| **霧** | 遠いものほど背景の色に溶ける（空気遠近法）。奥へ消えていく感じ |

```python
def view(p: V, cam: Camera = Camera()) -> V:
    """世界の点を「カメラから見た点」にする。カメラの位置を引いてから、傾きのぶん逆に回す。"""
    q = V(p.x - cam.x, p.y - EYE, p.z)
    return rotate(q, 0, 0, -cam.roll)
```

カメラを「世界の中の物」にしたのがポイント。すべての点を `view()` でカメラから見た座標に直してから
`project()` に渡す。カメラを動かしても投影の式は変わらない。

## 仕様

- 128 × 80 ドット、1 コマ 1/30 秒の固定刻み（g64 と同じ）。ブラウザは同じ式を 2 倍の板（256 × 160）で回す
- 小惑星は z = 48 で生まれ、速さ 10（よけるたび +0.35、上限 34）で迫る
- 自機は画面に収まる範囲（x ±3.2、y −0.8〜2.6）だけ動ける。小惑星もその範囲に出る
- ぶつかると ♥ −1 と 1 秒の点滅（無敵）。3 回で終わり
- 音：よけた（高く短く）・ぶつかった（低く長く）・おしまい。g73 と同じ作り方

## 板（`Screen`）の作り

画面は `list[bytearray]`——1 行が `RGB × 幅` のバイト列。面を塗るのは走査線ごとに
`row[left*3:(right+1)*3] = paint * (right - left + 1)` の**スライス代入 1 回**で済ませる。
ドットを 1 つずつ置くより速く、板を 2 倍（256 × 160、面積 4 倍）にしても描く時間は 1.0 ms → 1.1 ms。
`project(p, scale)` の `scale` は板の幅 ÷ 128 で、端末（1.0）とブラウザ（2.0）が同じ式を使う。

```python
def fill(self, points, color):        # 走査線で塗る
    for y in range(top, bottom + 1):
        ...  # 辺との交点 xs を集める
        self.rows[y][left * 3:(right + 1) * 3] = paint * (right - left + 1)
```

端末は 1 ドット = 1 文字幅（▀ で縦 2 ドット）なので 128 × 80 が上限。細かくしたいのはブラウザだけ。

## メモ

- **面の表裏は自動でそろえる。** 自機の面を手で書いたら裏返っていて、暗い塊に見えた。
  凸な立体なら「重心から見て外向き」で決められるので、`outward()` に任せる
- **視点を少し高くする**（`EYE`）と、自機が画面の下寄りに映って「後ろから見ている」感じになる
- **自機の動ける範囲は「画面に収まる幅」から逆算**した。z=4 で ±3.2。それより広いと画面の外へ出る

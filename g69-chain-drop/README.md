# g69 ぶよぶよ（落ちものパズル）

2 個組の玉が落ちてくる。同じ色が 4 つ以上つながると消え、上の玉が落ちてまたつながれば連鎖。積み上がったら終わり（エンドレス）。
消した数でレベルが上がり、落ちるのが速くなる。5 色。**中身は Python、絵はブラウザで Three.js**（2 本目）。端末は ▀ の 2D。

```
python3 main.py            # 遊ぶ（スペースで始める。← → 移動、↑ 回転、↓ 1 段、スペースで一気に落とす。q でやめる）
python3 main.py --check    # 決まりを確かめる
python3 main.py --sheet    # 遊んでいる場面を PNG に書き出す
```

ブラウザ版: https://hicocho.github.io/python-study/g69/ （左右スワイプで移動、タップで回転、下スワイプで一気に落とす）

## 主題

- **盤は 2 次元の列**：`grid[行][列]` に `Blob(color, uid)` か `None`。行 0 が一番下。見える 12 行の上に見えない 1 行（組が出る場所）
- **つながりの探索**：`find_groups()` は同じ色を幅優先（`deque`）で集める。4 つ以上の組だけ返す
- **連鎖の状態機械**：`FALL`（組が落ちる）→ `lock()` → `SETTLE`（浮いた玉が落ちる。見た目の時間は落ちた段数から）→ `begin_pop()`：組があれば `POP`（0.4 秒、連鎖 +1）→ `SETTLE` → … 無ければ次の組。段階ごとに `phase_left` を持つ
- **玉は uid で追う**：`apply_gravity()` は動いた玉の `(uid, 列, 前の行, 後の行)` を返す。端末もブラウザも、この列を読んで「落ちる途中」を描く。Three.js の球は uid ごとに 1 つで、作り直さず動かす
- **評価して選ぶ CPU**：`choose()` は 6 列 × 4 回転の全部を写しの盤に置いて `resolve()`（落ち着くまで進める純粋な関数）し、点・置いた高さ・でこぼこ・同じ色の隣で選ぶ。検査とブラウザの自動プレイに使う

## 点

消した数 × 10 × ボーナス（最低 1）。ボーナス = 連鎖（0, 8, 16, 32, 64, 96, …）+ 色数（0, 3, 6, 12, 24）+ 組の大きさ（5 個 2、6 個 3、…）。
4 つ 1 連鎖 = 40、2 連鎖目で 4 つ = 40 × 8 = 320。盤が空になれば全消し +1000。

## Three.js でやっていること

| もの | 作り方 |
|---|---|
| 盤 | 暗い箱の背板、金属の縁 3 本、薄い格子 |
| 玉 | `SphereGeometry` に `MeshPhysicalMaterial`（clearcoat でつや）。色ごとに材質を共有。消えるときは emissive の材質に替えて縮む |
| つながり | 同じ色の隣どうしを箱で橋渡し（使い回しの列 `links`。毎コマ数えて余りは隠す） |
| 影 | 落ちる先に半透明の球 2 つ |
| 次の玉 | 盤の右に小さい球 4 つ。並びが変わったときだけ作り直す |
| 粒 | 消えた瞬間に 10 + 4 × 連鎖 個。`Points` 300 個分に毎コマ `array.set()`。色は頂点色（`vertexColors`） |
| 光 | 主光・青い補助光・環境光・つやを作る `PointLight` |

## 仕様

- 落下 0.9 秒（レベル 1）、レベルごとに −0.07、下限 0.22。30 個消すごとにレベル +1。↓ で 0.05 秒
- 着地してから 0.25 秒は動かせる（↓ を押していれば即固まる）。回転は壁蹴り（相方の反対側 → 右 → 左 → 上）
- 記録：点と最大連鎖。端末は `records.json`、ブラウザは localStorage
- 音：移動・回転・着地・消える（連鎖ごとに短 3 度ずつ高く、5 段まで）・レベル・全消し・終了・ベスト

## 検証

- `--check`：つながり（5+5、斜めは別）、落下の列、点（40・組のボーナス・2 色）、`resolve` の 2 連鎖、組の動き（壁蹴り・時間と ↓・横向きは別々の高さ）、状態機械（pop1 → pop2 → 全消し）、レベルと終わり、自動で 3 種（124〜1000 組・最大 3〜4 連鎖）、板の大きさ、記録・音・状態行
- 端末：pty で 28 コマ/秒。矢印で動く
- ブラウザ：Playwright（SwiftShader）で 29〜30 コマ/秒、エラー無し。右スワイプで列 2 → 4、タップで回転、下スワイプで固まる。自動プレイ 90 秒で 220 組・レベル 14

## メモ

- 出る場所の判定 `spawn()` で `phase` を FALL に戻し忘れて、2 組目から動かなかった
- ↓ を押した瞬間に速く落ちるよう、`soft` の setter で `fall_left` を縮める

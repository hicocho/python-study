# g69 ぶよぶよ（落ちものパズル）

2 個組の玉が落ちてくる。同じ色が 4 つ以上つながると消え、上の玉が落ちてまたつながれば連鎖。積み上がったら終わり（エンドレス）。
消した数でレベルが上がり、落ちるのが速くなる。5 色。**中身は Python、絵はブラウザで Three.js**（2 本目）。端末は ▀ の 2D。

```
python3 main.py            # 遊ぶ（スペースで始める。← → 移動、↑ 回転、↓ 1 段、スペースで一気に落とす。q でやめる）
python3 main.py --check    # 決まりを確かめる
python3 main.py --sheet    # 遊んでいる場面を PNG に書き出す
```

ブラウザ版: https://hicocho.github.io/python-study/g69/ （左右スワイプで移動、タップで回転、下スワイプで一気に落とす）

## 主題

- **盤は 2 次元の列**：`grid[行][列]` に `Blob(color, uid)` か `None`。行 0 が一番下。見える 12 行の上に見えない 1 行（組が出る場所）
- **つながりの探索**：`find_groups()` は同じ色を幅優先（`deque`）で集める。4 つ以上の組だけ返す
- **連鎖の状態機械**：`FALL`（組が落ちる）→ `lock()` → `SETTLE`（浮いた玉が落ちる。見た目の時間は落ちた段数から）→ `begin_pop()`：組があれば `POP`（0.4 秒、連鎖 +1）→ `SETTLE` → … 無ければ次の組。段階ごとに `phase_left` を持つ
- **玉は uid で追う**：`apply_gravity()` は動いた玉の `(uid, 列, 前の行, 後の行)` を返す。端末もブラウザも、この列を読んで「落ちる途中」を描く。Three.js の球は uid ごとに 1 つで、作り直さず動かす
- **評価して選ぶ CPU**：`choose()` は 6 列 × 4 回転の全部を写しの盤に置いて `resolve()`（落ち着くまで進める純粋な関数）し、点・置いた高さ・でこぼこ・同じ色の隣で選ぶ。検査とブラウザの自動プレイに使う

## 点

消した数 × 10 × ボーナス（最低 1）。ボーナス = 連鎖（0, 8, 16, 32, 64, 96, …）+ 色数（0, 3, 6, 12, 24）+ 組の大きさ（5 個 2、6 個 3、…）。
4 つ 1 連鎖 = 40、2 連鎖目で 4 つ = 40 × 8 = 320。盤が空になれば全消し +1000。

## フィーバーとお題（2 回目の直し：「1 と 3 で」の 3）

- **フィーバー**：1 回の落としで 3 連鎖に達すると 12 秒。その間の消しは点 ×2（始まった連鎖の次の消しから）。フィーバー中に 3 連鎖するとさらに 12 秒延びる。`fever_until` の時刻で持つ（g67・g68 と同じ）
- **お題**：`MISSIONS` の表（文と `check(world)` の関数）を順に。1 回の判定で 1 つずつ達成、★ と +500。連鎖が落ち着いたときと、落ちている間（点・レベルのお題）に判定。ベストに ★ の数も残す
- 端末はフィーバー中に背景が脈打ち、縁が金色。状態行の右にお題

## Three.js でやっていること

| もの | 作り方 |
|---|---|
| 盤 | 暗い箱の背板、金属の縁 3 本、薄い格子 |
| 玉 | `SphereGeometry` に `MeshPhysicalMaterial`（clearcoat でつや）。色ごとに材質を共有。消えるときは emissive の材質に替えて縮む |
| つながり | 同じ色の隣どうしを箱で橋渡し（使い回しの列 `links`。毎コマ数えて余りは隠す） |
| 影 | 落ちる先に半透明の球 2 つ |
| 次の玉 | 盤の右に小さい球 4 つ。並びが変わったときだけ作り直す |
| 粒 | 消えた瞬間に 10 + 4 × 連鎖 個。`Points` 300 個分に毎コマ `array.set()`。色は頂点色（`vertexColors`） |
| 光 | 主光・青い補助光・環境光・つやを作る `PointLight` |
| 映り込み（2 回目の直し） | `RoomEnvironment` を `PMREMGenerator` で環境に。球がガラス玉のように部屋を映す。`envMapIntensity` は 0.3（0.9 では白く飛んだ） |
| ブルーム | `EffectComposer` → `RenderPass` → `UnrealBloomPass`（強さ 0.35、しきい値 0.85）→ `OutputPass`。消える玉は emissive 2.2 で光がにじむ。連鎖が深いほど強く、フィーバーは脈打つ |
| 着地の潰れ | 玉が「落ちていた → 止まった」瞬間を uid で見つけ、0.28 秒だけ横に広がり縦に縮む（`squash`） |
| 背景 | 上下で色の変わる板（頂点色。sRGB → 線形に直さないと明るく飛ぶ）と、奥でゆっくり回る粒 500 個 |

### 表現力（3 回目の直し：「1・2・3・4 を実行して」）

| もの | 作り方 |
|---|---|
| 玉が生き物に | 玉 1 つ = 体 ＋ 目 2 つ ＋ 黒目 2 つの `Group`（作るのは最初の 1 回）。落ちている間は縦に伸び（0.92 × 1.12）、待っている間は呼吸（±2.5%）、瞬きは玉ごとにずれた周期（`(time + uid × 1.7) % 3.8 < 0.13`）、黒目は落ちてくる組の方を見る |
| 消える演出 | 消えた所に広がる輪（`RingGeometry` の使い回し 24 個、0.4 秒で 5 倍・薄く）、消えた瞬間に全体が一瞬明るく（環境光を 1 コマだけ上げる）、連鎖の数を `CanvasTexture` の文字（`Sprite`）でぽんと出して上がりながら消す、粒は `LineSegments` で尾を引く（頭と尾の 2 頂点、尾は暗く） |
| 光と影 | `shadowMap` を有効に、主光が影を落とし（玉と橋 → 盤の背板）、主光はゆっくり動く。フィーバー中は `SpotLight` が盤を舐める（強さ 9。60 では白く飛んだ） |
| 場所 | `THEMES` の表（Python 側。端末の背景にも使う）：夜 → 夕焼け → 深海 → 星雲 → 黎明。背景の板・霧（`FogExp2`）・光の柱 3 本（canvas の帯の絵を貼った足し算の板。揺れて明滅）・粒の色を表から。変わったときだけ塗り直す |

## 仕様

- 落下 0.9 秒（レベル 1）、レベルごとに −0.07、下限 0.22。30 個消すごとにレベル +1。↓ で 0.05 秒
- 着地してから 0.25 秒は動かせる（↓ を押していれば即固まる）。回転は壁蹴り（相方の反対側 → 右 → 左 → 上）
- 記録：点と最大連鎖。端末は `records.json`、ブラウザは localStorage
- 音：移動・回転・着地・消える（連鎖ごとに短 3 度ずつ高く、5 段まで）・レベル・全消し・終了・ベスト

## 検証

- `--check`：つながり（5+5、斜めは別）、落下の列、点（40・組のボーナス・2 色）、`resolve` の 2 連鎖、組の動き（壁蹴り・時間と ↓・横向きは別々の高さ）、状態機械（pop1 → pop2 → 全消し）、フィーバーとお題（3 連鎖で始まる・×2 は次から・お題は順番どおり 1 つずつ）、レベルと終わり、自動で 3 種（124〜1000 組・最大 3〜4 連鎖）、板の大きさ、記録・音・状態行
- 端末：pty で 28 コマ/秒。矢印で動く
- ブラウザ：Playwright（SwiftShader）で 29〜30 コマ/秒、エラー無し。右スワイプで列 2 → 4、タップで回転、下スワイプで固まる。自動プレイ 90 秒で 220 組・レベル 14

## メモ

- 表現を足すたびに白飛びと戦った：光の柱は帯の絵（両端と上下が透ける）にしないと縞になる、スポットライトは 60 → 9、消えた瞬間の光も半分に。「派手にする」は足すより引く回数が多い
- 映り込みとブルームを入れた最初の版は、球がパステル色に、背景が白く飛んだ。原因は 3 つ：環境の強さ（0.9 → 0.3）、頂点色に sRGB の値をそのまま入れた（2.2 乗で線形に）、環境光の強さ。「置くだけで映える」ものほど、量は測って決める

- 出る場所の判定 `spawn()` で `phase` を FALL に戻し忘れて、2 組目から動かなかった
- ↓ を押した瞬間に速く落ちるよう、`soft` の setter で `fall_left` を縮める
- 自動プレイは「出る列に近いほど良い」を入れたら列 1・2 だけに積んで 21 組で自滅した。置いた高さの 2 乗の罰に

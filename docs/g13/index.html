迷路レース

赤があなた、青が探索ロボット。同じ左上から出て、先に黄色いゴールに着いたほうの勝ちです。ロボットは深さ優先で「実際に歩いて」探すので、行き止まりでは戻ってきます。下のボタンで DFS・BFS・A* がどう探すかを 1 歩ずつ見られます。

Python を読み込んでいます… （初回は数秒かかります）

このページは Python のコードがブラウザの中でそのまま動いています（PyScript）。 サーバーはなく、迷路の生成もロボットの探索もすべて手元の端末で行われます。

耳コピ2（音色とリズム）

耳コピ1 の続き。お題が本物のリズムで鳴るようになり、当てるものが「音の高さ」から「音の高さと長さ」に増えます。音色はサイン・三角・オルガン・のこぎりの 4 種で、曲が進むと変わります（倍音が多い音ほど高さが取りにくい）。音を出してお使いください。

曲 1 / 47 ・ ？ ・ 音色 サイン 聞いた 0 回 ・ 答え合わせ 0 回

決まった音（もう動かない） 打ち込み中の音 1 音目の高さの目盛り 下の帯の長さ＝その音の長さ

やること：流れた旋律と同じ音の並びを、長さまで合わせて打ち込む。 1 音目だけは最初から出ています（そこからの上がり下がりを当てる遊びです）。
  1. ▶ お題を聞くを押す。何度でも聞けますが、回数が少ないほど★が多い。
  2. 鍵盤を押すと、その音が鳴って左から順に積まれます。間違えたら 1つ消す。
  3. 音が長ければ ♩ 長く、短ければ ♪ 短く（矢印キーでも）。置いたあとから直せます。
  4. 全部そろったら 答え合わせ。高さと長さの両方が合った音だけ青くなって残ります。
長さの選び先はその曲に出てくる長さだけ（たいてい 2 種類）。 合っているかどうかしか教えません。耳で確かめてください。

曲について（なぜこの 47 曲なのか）
      

      小学校で習う童謡・唱歌のうち、著作権の切れたものだけを選びました。日本の保護期間は
      没後 70 年ですが、2018 年の延長はその時点でまだ切れていない作品にしか及びません。
      つまり 1967 年以前に亡くなった作曲家の曲は、旧法の 50 年で満了済みです。
      この線で選んでいます（山田耕筰は 1965 年没なので「赤とんぼ」が入り、井上武士は 1974 年没なので
      「チューリップ」は入っていません）。旋律は 1 曲ずつ耳で確かめました。

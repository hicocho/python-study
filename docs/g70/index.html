アイランド・ダイス

島をうねうね進むボードゲーム。サイコロを指ではらって本当に転がし、止まった目の数だけコマが進みます。止まったマスでお金が増えたり減ったり、カードを引いたり。分かれ道では山を越える近道も。自分 ＋ CPU 3 人（性格が違う）。全員がゴールしたら所持金で順位。中身は Python、サイコロの物理は Cannon-es、絵は Three.js。音を出してお使いください。

出目 – ・ 0 勝 / 0 回 ・ – コマ/秒

 



    

      やること：あなたの番になったら、画面の上で指をはらうとサイコロが飛ぶ（強さと向きが反映。パソコンはスペースでも）。止まった目の数だけ進む。分かれ道ではボタンで道を選ぶ（キーは 1 と 2）。
      
    
        
  1. マス：緑 お金が増える（300〜800）、赤 減る（200〜500）、青 カード（給料日・宝くじ・税金・追い風・迷子・昼寝…9 種）、灰 1 回休み、橙 宝（最初に着いた 1 人だけ +1500）。
    2. 
        
  2. 分かれ道：本道か、山を越える近道（6 マス短いが減るマスが多い。宝あり）。CPU は性格で選ぶ：タケシは堅実、ミカは賭け、ゴロウはいじわる（負けていると近道）。
    3. 
        
  3. ゴールは超えても止まる。着いた順に +3000 / +2000 / +1000 / +500。全員がゴールしたら所持金で順位。
    4. 
        
  4. サイコロは Cannon-es という物理エンジンが本当に転がし、止まったときに上を向いた面を読んでゲームに渡している。CPU の番も同じサイコロが転がる。
    5. 
      

      

        マスは表と道の網：1 マス 1 行、next で次を指す。分かれ道は next が 2 つ
        手番の状態機械：ROLL → MOVING → FORK → EVENT → 次の人
        出目は外から渡す：端末は乱数、ブラウザは物理
        地形は式：height(x, z) から地図も 3D の島も
      

    


    
Python を読み込んでいます… （初回は数秒かかります）

  


  

    このページは Python のコードがブラウザの中でそのまま動いています（PyScript）。
    島の高さ・マスの表・手番の状態機械・出来事・CPU の性格は CLI 版と 1 文字も違いません。
    端末は上から見た地図を ▀ で描き、出目は乱数。ここでは同じ height() から 3D の島を作って Three.js で描き、サイコロは Cannon-es で転がして上の面を読んでいます。

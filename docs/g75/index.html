タイピング1（キーボードと指）

ブラインドタッチの練習。上の文を見ながら、手元を見ずに打ちます。キーボードの絵に次に押すキーとどの指で押すかが出ます。ホームポジション → 上の段 → 下の段 → 数字と段階を踏み、正確さ 95% 以上で次へ。配列は JIS です。

段階 1 / 4 ・ ホームポジション 打った 0 ・ ミス 0 ・ 正確さ 100%

日本語入力がオンになっています。英数に切り替えてください（キーが届きません）。


    

    


    

      いま打つ字
      間違えて押したキー
      キーの色 ＝ 指（下線はホームポジション）
    

    

      やること：文のとおりにキーを打つ。手元は見ない。キーボードの絵で場所と指を確かめる。
      
    
        
  1. まず f と j の突起に人さし指を置く（ホームポジション）。
    2. 
        
  2. 黄色の字を打つ。合えば次へ。違えば赤く光って、正しいキーを押すまで進みません。
    3. 
        
  3. かたまりの間の空白は親指で。
    4. 
        
  4. 打ち終わると成績が出ます。正確さ 95% 以上なら「つぎの段階へ」、届かなければ別の文でもう一度。
    5. 
      

      速さより正確さ。間違えた指を覚えるのがいちばんの近道です。

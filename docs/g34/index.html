ギャラガ風（急降下と敵の弾）

5 段階の 3 つ目。席に着いた敵が状態機械で動き、自機めがけて急降下して弾を撃ってきます。当たると残機が 1 つ減り、3 機で終わり。← → で移動、スペースで撃つ。

SCORE 0 残機 ▲▲ ・ 敵 32 ・ 降下 0 ・ 命中 -

← → か A / D で移動、スペースで撃つ（同時に 2 発まで）。降下してくる敵と赤い弾をよける。携帯はボタンで。

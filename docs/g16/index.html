宇宙船

慣性で滑る船を回転と加速だけで操り、黄色いリングから順に 5 つくぐります。茶色い星には引力があり、ぶつかると船が壊れます。船は 3 機。画面の端は反対側につながっています。

リング 0 / 5 ・ 船 3 0.0 秒 ・ 速さ 0

← → で回転、↑ で加速

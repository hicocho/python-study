深宇宙シューティング

宇宙船で星雲の中を奥へ進みながら、迫ってくる小惑星を撃ち落とします。60 秒のステージ、体力 3・残機 3。大きい小惑星は撃つと割れます。ゲームの中身は Python、絵は Three.js（星・霧・光・岩の形は GPU が描きます）。スマホは画面のどこでも指を動かして押すだけ（傾きでも操作できます）。音を出してお使いください。

面 1/1 星雲の入口 ・ 残り 60.0 秒 ・ 体力 ■■■ ・ 機 3 点 0 ・ 連続 0（×1） ・ 命中 0/0 ベスト 0 ・ – コマ/秒

 

傾きで操作するには、上のボタンを押して許可してください（スマホ・タブレット）

やること：「スタート」のあと、画面のどこでも指を動かすと機体が追いかけ、押している間レーザーを連射（パソコンは矢印か w a s d、スペースで撃つ）。
  1. 奥から小惑星が迫ってくる。半分はあなたの今いる場所を狙って飛んでくる。大（+10）は撃つと中 2 つ（+20）に、中は小 2 つ（+40）に割れる。
  2. 体当たりすると体力が 1 減り、1.6 秒無敵。体力 0 で 1 機失う（3 機で終わり）。
  3. 続けて当てると 5 発ごとに倍率が上がる（×4 まで）。体当たりで 0 に。
  4. 60 秒で 1 面。時間が進むほど小惑星は速く、多くなる。
奥行きのある世界：x・y・z で物を持ち、カメラは機体の後ろ上 透視投影 1 行：端末は 中心 + FOCUS × (物 − カメラ) / 奥行き で描く 球の当たり判定：距離 < 半径の和 Three.js：同じ世界を Mesh に写し、光と霧は GPU に任せる

Python を読み込んでいます… （初回は数秒かかります）

このページは Python のコードがブラウザの中でそのまま動いています（PyScript）。 世界・小惑星の出方と割れ方・当たり判定・点・カメラの位置は CLI 版と 1 文字も違いません。 端末は透視投影の式で丸と点を ▀ の並びに描き、ここでは同じ世界を Three.js の物に写して GPU に描かせています（星・霧・光・岩の形は Three.js）。

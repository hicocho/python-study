2 個組の玉が落ちてきます。同じ色が 4 つ以上つながると消え、上の玉が落ちてまたつながれば連鎖。積み上がったら終わり。消した数でレベルが上がり、落ちるのが速くなります。5 色。ゲームの中身は Python、絵は Three.js（つやのある球・目と瞬き・映り込み・影・光のにじみ（ブルーム）・消える粒は GPU）。音を出してお使いください。

レベル 1 ・ 点 0 ・ 最大 0 連鎖 消した 0 ・ 組 0 ・ ベスト 0 ・ – コマ/秒 お題 2 連鎖を出す ・ ☆☆☆☆☆☆☆☆☆☆

 

やること：盤の上で左右にスワイプすると 1 マスずつ動き、タップで回転、下にスワイプで一気に落とす（パソコンは ← → 移動、↑ か x 回転、z 逆回転、↓ 速く、スペースで一気に）。
  1. 同じ色が縦横に 4 つ以上つながると消える。消えた上の玉が落ちてまたつながると連鎖。連鎖するほど点が跳ね上がる（1 連鎖 40 → 2 連鎖で 8 倍 → 3 連鎖で 16 倍…）。
  2. 薄い玉は落ちる先（影）。着地してから 0.25 秒は動かせる。
  3. 30 個消すごとにレベルが上がり、落ちる速さが 0.9 秒 → 0.22 秒まで縮む。
  4. 盤を空にすると全消し +1000。真ん中の列の一番上がふさがると終わり。
  5. フィーバー：3 連鎖以上で 12 秒、点が 2 倍。その間に連鎖するとさらに延びる。3 連鎖からは消える瞬間がスローモーションになり、カメラが寄る。
  6. お題：「2 連鎖を出す」から順に 10 個。達成すると ★ と +500。
  7. レベルが上がると場所が変わる：夜 → 夕焼け → 深海 → 星雲 → 黎明。
盤は 2 次元の列：grid[行][列]、行 0 が下、見えない行が 1 つ つながりの探索：同じ色を幅優先で集める（flood fill） 連鎖の状態機械：FALL → SETTLE → POP → SETTLE → … 玉は id で追う：落ちても Three.js の球は動かすだけ

Python を読み込んでいます… （初回は数秒かかります）

このページは Python のコードがブラウザの中でそのまま動いています（PyScript）。 盤・つながりの探索・落下・点・連鎖の状態機械・自動プレイは CLI 版と 1 文字も違いません。 端末は ▀ の並びに丸を描き、ここでは同じ盤の玉を Three.js の球に写して GPU に描かせています（つや・光・消える粒は Three.js）。

軽飛行機で輪をくぐる

峡谷を低空で縫い、130 m おきの輪を順にくぐってタイムを競います。コースは 3 つ（峡谷・海岸・高原）＋毎回違う地形の「ランダム」。狭い峡谷・三連橋・S 字・トンネル・滝の上昇。3D はライブラリを使わず自分で書きました——向きを 3 本のベクトルで持つ 3 軸の回転、内積だけで見るカメラ、高さの表から作る地形、傾く地平線。音を出してお使いください。

峡谷 ・ 0:00.00 ・ 輪 0/42 ・ 外し 0 ・ 連続 0 ・ 低空 −0.0 s ・ ベスト --:--.-- 区間 谷 ・ 速さ 65 m/s ・ 高度 120 m ・ 方位 000 ・ – コマ/秒

 



    

      
      
      
      
    

    

      
      
      
      
      
    

    

      
      
      
      
    

    

      
      
    

    

      
      
    

    
    

      
      
    

    
傾きで操縦するには、上のボタンを押して許可してください（スマホ・タブレット）


    

      やること：「スタート」で 3・2・1 のあと出発。← → で翼を傾けると曲がり（離すと水平に戻る）、↑ ↓ で機首の上げ下げ、▲ ▼ でスロットル 3 段階。峡谷を縫って橙の輪を順にくぐる。菱形の印が次の輪、画面の外なら縁の矢印。
      
    
        
  1. 輪の面をまたいだとき中心から 16 m 以内なら「くぐった」。外したら +3 秒で次へ（戻らない）。連続でくぐると連続数が出ます。
    2. 
        
  2. くぐると 1 秒のブースト（連続なら長く）。高度 8 m 未満を 1 秒続けるごとに −0.5 秒（低空ボーナス）。
    3. 
        
  3. 岩柱をよけ、赤い橋の下をくぐる。岩柱・橋・谷の壁・地面にぶつかると跳ね返って減速（画面の縁が赤く）、ブーストも切れる。
    4. 
        
  4. 区間：谷 → 狭い峡谷（幅半分）→ 三連橋（橋の下を 3 回）→ S 字（輪が大きく左右）→ 谷 → トンネル（暗い筒。壁で跳ね返る）→ 谷 → 滝の上昇（谷底が 180 m 上る）。
    5. 
        
  5. コース：峡谷（8 区間の定番）／海岸（低い谷と川、橋が多い）／高原（雪と 2 本のトンネル）／ランダム（種から作る。毎回違う道すじと区間）。合計タイム（走行＋罰−低空）のベストがコースごとにこのブラウザに残ります。
    6. 
        
  6. 天気：晴れ／雨（暗く、雨が斜めに）／霧（輪が直前まで見えない）／夕方／雪（地面が白い）。ランダムのコースは天気も毎回変わります。
    7. 
        
  7. スマホの傾きで操縦できます（ブラウザ版だけ）。「📱 傾きで操縦」を押して許可すると、端末を左右に傾けて曲がり（25° で押し切り。キーと違って傾けた量だけ曲がる）、手前に起こすと機首上げ、奥へ倒すと機首下げ。持った角度を基準（前後 40°）にしています。iPhone は許可のダイアログが出ます。うまく反応しないときは、画面の回転ロックを外すか、ボタン操縦に戻してください。
    8. 
      

      

        3 軸の回転：前・上・右の 3 本を機体の軸まわりで回す
        基底で見るカメラ：右・上・前との内積がカメラ座標
        ハイトマップ：高さの表 → 地形の網、法線で陰影
        傾く地平線：水平で無限に遠い向きを 2 つ投影した直線
      

    


    
Python を読み込んでいます… （初回は数秒かかります）

ブロック崩し

バーで玉を跳ね返してブロックを消します。文字で描いた 8 面、玉は 3 つ。硬い・鉄・爆発・動くブロック、連続で消すと倍率。スマホは画面のどこでも指を左右に動かすだけ（傾きでも操作できます）。音を出してお使いください。

面 1/8 はじまり ・ 残り 48 個 ・ 玉 3 点 0 ・ 連続 0（×1） ・ 速さ 42 ベスト 0 ・ – コマ/秒

 

傾きで操作するには、上のボタンを押して許可してください（スマホ・タブレット）

やること：「スタート」のあと、画面をタップで玉を放す。画面のどこでも指を左右に動かすとバーが追いかける（パソコンはマウスか ← →、スペースで放す）。
  1. バーの真ん中に当てると真上、端に当てるほど浅い角度（最大 65°）で返る。狙いたい方向の逆側で受ける。
  2. ふつうのブロック +10。硬い（灰色）は 2 回で +20、鉄（金色）は壊れない、爆発（橙に芯）は周り 8 つも壊す +30、動く（水色）は左右に揺れる +30。
  3. バーに戻るまでに続けて壊すと 3 個ごとに倍率が上がる（×4 まで）。
  4. 打ち返すたびに少し速くなる。落とすと玉が 1 つ減って速さが戻る。8 面を全部消したらクリア。
文字の地図：1 面 = 文字の並び 1 枚、文字 → 種類は表 軸ごとの当たり判定：x を動かして調べ、次に y 細かい歩み：1 コマを 1 ドットずつ進めてすり抜けを防ぐ 角度は当たった場所：バーのどこに当たったかで決まる

Python を読み込んでいます… （初回は数秒かかります）

このページは Python のコードがブラウザの中でそのまま動いています（PyScript）。 面の地図・玉の歩みと当たり判定・点と連続・描く処理は CLI 版と 1 文字も違いません。 端末は 120 × 84 ドットを ▀ の並びで、ここでは同じ式を 5 倍の板（600 × 420）で回して canvas に出しています。

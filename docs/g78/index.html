小惑星をよける（3D）

宇宙船の後ろから見た視点で、迫ってくる小惑星をよけます。3D はライブラリを使わず自分で書きました——3D の点を回し、透視投影で画面に落とし、奥の面から塗って、光の向きで陰影を付ける。全部 Python です。音を出してお使いください。

よけた 0 ・ 残り ♥♥♥ 速さ 10.0 ・ – コマ/秒 


    

      
      
      
      
    

    


    

      やること：矢印キー（または w a s d、画面のボタン）で宇宙船を動かし、小惑星をよける。
      
    
        
  1. 小惑星は奥から迫ってきます。近づくほど大きく、回りながら来ます。
    2. 
        
  2. ぶつかると ♥ が 1 つ減り、しばらく点滅します。3 回で終わり。
    3. 
        
  3. よけるたびに速さが上がります。どこまでいけるか。
    4. 
      

      

        遠近：近いものは大きい（x' = x / z）
        視差：近い星ほど速く流れる
        隠面：奥の面から描き、裏側の面は描かない
        陰影：面の向きと光の向きの内積

ワープ・トンネル

宇宙船の後ろから見た視点で、迫ってくる小惑星をよけます。3D の仕組み（回転・透視投影・当たり判定・カメラの追従と揺れ）は Python で自分で書き、このページでは同じ世界を Three.js に写して GPU が描いています（星雲・光のにじみ・粒・でこぼこの岩）。端末版は同じ式を ▀ で描きます。音を出してお使いください。

点 0 ・ よけた 0 ・ コンボ ― ・ ベスト 0 ステージ 1 ・ ゲート あと 10 残り ♥♥♥ ・ 速さ 10.0 ・ – コマ/秒

 



    

      
      
      
      
    

    

      
      
    


    

      やること：「スタート」（スペースでも）で始め、矢印キー（または w a s d、画面のボタン、画面をなぞる）で宇宙船を動かし、小惑星をよける。p か画面タップで一時停止。
      
    
        
  1. 小惑星は奥から迫ってきます。近づくほど大きく、回りながら来ます。いまの位置のままだとぶつかるものは赤みがかります。
    2. 
        
  2. ぶつかると ♥ が 1 つ減り、しばらく点滅します。3 回で終わり。
    3. 
        
  3. よけるたびに速さが上がります。速いほど視野が広がり、星が流れます。どこまでいけるか。
    4. 
        
  4. よけた数が 10 になるたびに緑のゲートが来ます。中を通れば ♥ が 1 つ戻り、ステージが進みます。ステージが進むと小惑星の出方が増えます（1 個 → 左右 2 個 → 横一列の帯 → 大きいの）。
    5. 
        
  5. 終わるとベスト（点・最高コンボ・よけた数）がこのブラウザに残ります。
    6. 
        
  6. ギリギリで通ると点が高い：スレスレ +3、近い +2、それ以外 +1。スレスレ・近いが続くとコンボで ×2 ×3 …（×5 まで）。遠くをよけるか、ぶつかるとコンボは 0。ぶつかると画面が揺れます。
    7. 
      

      
ブラウザ版の表現（2026-09-18）：宇宙はキューブマップで自機の金属に映り、岩は法線マップの岩肌、ワープのトンネルは自分で書いたシェーダ、粒は GPU が動かす（4000 個）。速いほど色がずれて端が暗くなり、噴射が青白く伸びる。輪を抜けると一瞬光り、ゲートで後ろに引かれる。岩は砕け、すれると光る。ステージごとに星雲の色と惑星が変わる。ぶつかった瞬間はスローでカメラが寄り、終わると自機の周りを回る。音は Tone.js（エンジンは速さで音程が上がり、スレスレは通った側から風切り）。

      

        遠近：近いものは大きい（x' = x / z）
        視差：近い星ほど速く流れる
        隠面：奥の面から描き、裏側の面は描かない
        陰影：面の向きと光の向きの内積
      

    


    
Python を読み込んでいます… （初回は数秒かかります）

  


  

    このページは Python のコードがブラウザの中でそのまま動いています（PyScript）。
    3D の点・回転・透視投影・面を塗る処理・隠面消去・陰影・世界の動きは
    CLI 版と 1 文字も違いません。端末は 128 × 80 ドットを ▀ の並びに自分で塗り、ここでは同じ世界（位置・向き・カメラ・画角）を Three.js の物に写して GPU に描かせています（2026-09-18 に Three.js 化。星雲・ブルーム・粒・岩の質感は Three.js）。

物理の積み木（剛体の箱）

物理 3 段階の 1 つ目。重力・跳ね返り・摩擦・回転を自分で書いています。箱を落とすと床で弾み、傾いた角から落ちて回り、動きが小さくなると眠って完全に止まります（暗くなった箱が眠っている箱）。まだ箱どうしはすり抜けます——それは次の課題。

箱 0 ・ 動いている 0 運動エネルギー 0

矢印か A / D で位置、スペースで落とす、R でやり直し。携帯はボタン。

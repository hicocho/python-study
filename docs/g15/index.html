ピンボール

右のレーンから打ち出して、青いバンパーに当てると 100 点。下のフリッパーで打ち返します。ボールは 3 つ。重力も斜めの壁の反射も Python で計算しています。

得点 0 ボール 3

Z / X でフリッパー、スペースで打ち出す

Python を読み込んでいます… （初回は数秒かかります）

このページは Python のコードがブラウザの中でそのまま動いています（PyScript）。 サーバーはなく、重力も反射もすべて手元の端末で計算しています。

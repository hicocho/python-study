ブロック崩し

パドルでボールを打ち返して、40 個のブロックを全部壊します。パドルの端に当てるほど横に飛び、8 個壊すごとにボールが速くなります。ボールは 3 つ。

得点 0 ・ ボール 3 残り 40 個 ・ 速さ 16

← → でパドル / Enter でスタート

Python を読み込んでいます… （初回は数秒かかります）

このページは Python のコードがブラウザの中でそのまま動いています（PyScript）。 サーバーはなく、ボールの物理も当たり判定もすべて手元の端末で行われます。

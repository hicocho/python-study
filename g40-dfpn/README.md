# g40 将棋（詰将棋 df-pn）

将棋 6 段階の 4 つ目。g39 の「深さを限った全探索」を **df-pn（depth-first proof-number search）** に替えます。局面ごとに**証明数**（あと何局面調べれば「詰み」と言えるか）と**反証数**（あと何局面で「不詰」と言えるか）を持ち、攻め方は証明数が最小の手、受け方は反証数が最小の手から掘る。結果は**置換表**に残すので同じ局面を 2 度調べない。5 手詰で全探索の 1/3〜1/5 の局面数、**7 手詰**も 1〜2 秒で解けるようになりました。問題は 7 手詰 3 題を足して 11 題。

今回の主題は 4 つです。

- **df-pn** — 証明数・反証数と「しきい値」の再帰。攻め方の局面（OR）は子の pn の最小・dn の合計、受け方の局面（AND）は pn の合計・dn の最小
- **置換表 `dict[int, tuple]`** — Zobrist ハッシュ（g38）→ (pn, dn)。探索の結果を局面に紐づけて再利用する。手順の復元も置換表をたどるだけ
- **`math.inf`** — 「無限」を数として扱う。`min(INF, sum(...))` で溢れを止め、`th - dn + best_dn` の引き算では `INF` を特別扱い
- **`itertools.count` と `operator.itemgetter`** — 訪れた回数は `next(self.counter)`、子の pn / dn の取り出しは `map(itemgetter(index), children)`

## 仕様

- 詰み = 根の証明数が 0。不詰 = 反証数が 0。未探索の局面は (1, 1)
- 攻め方の局面で手数いっぱいなら (∞, 0)。攻め方に王手がなければ (∞, 0)、受け方に受けがなければ (0, ∞)
- 子のしきい値: 攻め方なら「2 番目に小さい pn + 1」と「親の dn の残り」、受け方はその逆
- 手順の復元: 置換表で pn == 0 の子をたどる。受け方は最も長く粘る手を選ぶ（全探索の答えと一致）
- 余詰: 初手を 1 つずつ変えて受け方の局面から探し、2 つ以上詰めば余詰

## メモ

### 証明数・反証数

```python
if attacker:                       # OR 節点: どれか 1 つ詰めばよい
    pn = min(c[0] for c in children)
    dn = min(INF, sum(c[1] for c in children))
else:                              # AND 節点: 全部詰まないといけない
    pn = min(INF, sum(c[0] for c in children))
    dn = min(c[1] for c in children)
```

攻め方の局面は「1 つ詰めばいい」ので、詰めるのに要る局面数は子の最小、不詰を示すには全部の子で示す必要があるので合計。受け方はその逆。この数が小さい子ほど「決着に近い」ので、そこを掘る。

### しきい値で「掘りすぎ」を止める

深さ優先で最良の子に潜るとき、「2 番目の子の pn + 1」をしきい値にして渡す。潜った先で pn がそれを超えたら戻ってきて、2 番目の子に切り替える。これが df-pn の「深さ優先なのに最良優先と同じ順で調べる」仕掛け。`INF` との引き算は `nan` になるので `INF if th == INF else th - dn + best_dn` と分ける。

### 置換表と手順の復元

探索の結果は `self.table[zobrist] = (pn, dn)`。同じ局面に別の手順で着いても再利用する。詰んだあとの手順は、置換表で `pn == 0` の子をたどれば出る（`line()`）。受け方は複数の子が pn == 0 なので、最も長く粘る手を選ぶと g39 の全探索の答えと同じになる。

### 7 手詰の作り方

5 手詰の玉を 1 マスずらし、攻め方の持ち駒を 1 枚足して、df-pn で「7 手で詰み、5 手では詰まず、余詰なし」を確かめる。ランダムに駒を置くやり方（g39）では 7 手詰が 300 局面試して 0 個だったが、この「延長」なら 5 分で 4 個。9 手詰は同じ方法で 7 分回しても見つからず、今回は 7 手まで。

### `itertools.count` と `operator.itemgetter`

`count(1)` は 1, 2, 3, … を無限に出すイテレータ。`self.nodes = next(self.counter)` で「何回目の訪問か」。`itemgetter(0)` は `lambda c: c[0]` と同じで、`map` に渡すと読みやすい。

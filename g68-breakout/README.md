# g68 ブロック崩し

バーで玉を跳ね返してブロックを消す。文字で描いた 8 面、玉は 3 つ。連続で消すと倍率が上がる。
**スマホで扱いやすいゲーム**として作った：画面のどこでも指を左右に動かすとバーが追いかける。傾きでも操作できる。

```
python3 main.py            # 遊ぶ（スペースで始める・玉を放す。← → か a d でバー。q でやめる）
python3 main.py --check    # 決まりを確かめる
python3 main.py --sheet    # 面ごとの場面を PNG に書き出す（stage1.png 〜 stage8.png）
```

ブラウザ版: https://hicocho.github.io/python-study/g68/

## 主題：文字の地図と、軸ごとの当たり判定

- **文字の地図**：1 面は文字の並び 1 枚（`STAGES`）。`.` は空き、文字 → ブロックの種類は表 `KINDS`（点・当たり回数・色）。面を足すのは地図 1 枚
- **軸ごとの当たり判定**：玉を x だけ動かして調べ、次に y だけ動かして調べる（`World.walk`）。横から当たれば左右に、縦から当たれば上下に跳ね返る、が自然に決まる。「どの面に当たったか」の場合分けを書かない
- **細かい歩み**：速い玉（1 コマ 2〜3 ドット）が高さ 4 のブロックをすり抜けないよう、1 コマを 1 ドットずつの歩みに分ける（`steps = ceil(speed × dt)`）
- **角度は当たった場所**：バーの中心からのずれ −1〜+1 × 65° で返る角度が決まる（`bounce_paddle`）。真ん中は真上、端は浅い。速さは向きと分けて持ち、毎コマ速さだけそろえる

## ブロック

| 文字 | 種類 | 当たり | 点 |
|---|---|---|---|
| `r o y g b p` | ふつう（赤・橙・黄・緑・青・紫） | 1 | 10 |
| `H` | 硬い（1 回目でひび） | 2 | 20 |
| `S` | 鉄（壊れない。跳ね返るだけ） | — | 0 |
| `X` | 爆発（周り 8 つも壊す。鉄は残る。爆発は連鎖） | 1 | 30 |
| `>` `<` | 動く（±8 ドット、3 秒周期で左右に揺れる） | 1 | 30 |

面：はじまり → ピラミッド → 硬い壁 → 爆弾畑 → 鉄の柱 → 動く列 → 城 → 最後の砦。壊せるブロックが無くなれば次の面。

## 仕様

- 板 120 × 84。バー幅 18、玉の半径 1.3。玉の速さは 42 + 面 × 3 + 打ち返し × 0.6（+14 まで）ドット/秒。落とすと玉が 1 つ減り速さが戻る
- 縦の速さは速さの 25% を下回らない（横に走り続けない）
- 連続：バーに戻るまでに壊した数。3 個ごとに倍率 +1（×4 まで。壊した直後の連続数で決まる）
- ベスト：点と到達した面。端末は `records.json`、ブラウザは localStorage
- 音：壁・バー・ブロック・カン・爆発・放す・落とす・面クリア・終了・ベスト

## 入口（ブラウザ）

- 指：`pointermove` で指の x → `world.aim(x)`。バーは 1 秒に 140 ドットで目標を追う（`PADDLE_SPEED`）ので、指が飛んでも滑らかに動く
- 傾き：`deviceorientation` の gamma を ±15° で端まで（g81 と同じ許可の流れ）
- キー：← → は押している間だけ動く（keydown/keyup）

## 検証

- `--check`：面の地図（行の長さ・知らない文字・全種類を使う）、跳ね返り（壁・天井・バーの真ん中は真上・端は 65°・落とす）、ブロック（ふつう・硬い・鉄・爆発の範囲・動く・速い玉もすり抜けない）、連続と倍率、速さの階段、自動で全 8 面（843 秒、落とし 0）、玉 3 つでどこまで、板の大きさ、記録・音・状態行
- 端末：pty で 26 コマ/秒。矢印キーと a d でバー、スペースで放す
- ブラウザ：Playwright で 29 コマ/秒、エラー無し。自動操縦の狙いをマウスの移動に変えて面 2 まで

## メモ

- 自動操縦は「玉が落ちてくる x を先読みし、残っているブロックの方へ返すよう、その逆側で受ける」。玉 99 個で全面クリアできた
- `remaining() == 0` で面が終わるので、検査で「ブロック無し」の板を作ると次の面に進んでしまう。壊れない鉄や余りを 1 つ置く

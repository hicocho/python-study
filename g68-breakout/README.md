# g68 ブロック崩し

バーで玉を跳ね返してブロックを消す。文字で描いた 8 面、玉は 3 つ。連続で消すと倍率が上がる。
**スマホで扱いやすいゲーム**として作った：画面のどこでも指を左右に動かすとバーが追いかける。傾きでも操作できる。

```
python3 main.py            # 遊ぶ（スペースで始める・玉を放す。← → か a d でバー。q でやめる）
python3 main.py --check    # 決まりを確かめる
python3 main.py --sheet    # 面ごとの場面を PNG に書き出す（stage1.png 〜 stage8.png）
```

ブラウザ版: https://hicocho.github.io/python-study/g68/

## 主題：文字の地図と、軸ごとの当たり判定

- **文字の地図**：1 面は文字の並び 1 枚（`STAGES`）。`.` は空き、文字 → ブロックの種類は表 `KINDS`（点・当たり回数・色）。面を足すのは地図 1 枚
- **軸ごとの当たり判定**：玉を x だけ動かして調べ、次に y だけ動かして調べる（`World.walk`）。横から当たれば左右に、縦から当たれば上下に跳ね返る、が自然に決まる。「どの面に当たったか」の場合分けを書かない
- **細かい歩み**：速い玉（1 コマ 2〜3 ドット）が高さ 4 のブロックをすり抜けないよう、1 コマを 1 ドットずつの歩みに分ける（`steps = ceil(speed × dt)`）
- **角度は当たった場所**：バーの中心からのずれ −1〜+1 × 65° で返る角度が決まる（`bounce_paddle`）。真ん中は真上、端は浅い。速さは向きと分けて持ち、毎コマ速さだけそろえる

## ブロック

| 文字 | 種類 | 当たり | 点 |
|---|---|---|---|
| `r o y g b p` | ふつう（赤・橙・黄・緑・青・紫） | 1 | 10 |
| `H` | 硬い（1 回目でひび） | 2 | 20 |
| `S` | 鉄（壊れない。跳ね返るだけ） | — | 0 |
| `X` | 爆発（周り 8 つも壊す。鉄は残る。爆発は連鎖） | 1 | 30 |
| `>` `<` | 動く（±8 ドット、3 秒周期で左右に揺れる） | 1 | 30 |

面：はじまり → ピラミッド → 硬い壁 → 爆弾畑 → 鉄の柱 → 動く列 → 城 → 最後の砦。壊せるブロックが無くなれば次の面。

## パワーアップ（2 回目の直し：「1 → 2 の順で」の 1）

壊すと 15% でカプセルが落ちる（`POWERS` の表、重みで抽選）。バーで拾うと効く。効き目は「切れる時刻」`powers[kind]` で持つ。

| 印 | 名前 | 効き目 |
|---|---|---|
| 点 3 つ | 玉が 3 つ | いま飛んでいる玉から ±25° に 2 つ分ける。1 つ残っていれば落としたことにならない |
| 長い棒 | バーが広い | 1.5 倍、12 秒（縮むと入れ替わる） |
| 矢 | 貫通 | 8 秒、ブロックを止まらずに壊す（鉄だけ跳ね返る） |
| 砂時計 | ゆっくり | 速さ 0.65 倍、8 秒 |
| U | 磁石 | 10 秒、玉がバーにくっつく。拾った場所の角度で放す（`Ball.offset`） |
| 短い棒 | 縮む（悪い） | 0.6 倍、8 秒 |
| 縦線 2 本 | レーザー（3 回目の直し） | 8 秒。タップ（スペース）でバーの真上に光線、一番下の壊せるブロックを 1 つ削る。鉄で止まる。連射は 0.35 秒おき |
| 炎 | 火の玉 | 8 秒。当てたブロックの上下左右も壊す（爆発の弱い版がずっと続く） |
| 玉 | 玉が 1 つ増える | バーに乗った玉が 1 つ足される（5 つまで）。タップで放す |
| ＋ | 1UP | 残機 +1（5 つまで）。重み 4 でめったに出ない |
| 下線 | バリア | 画面の下に線。玉を 1 回だけ跳ね返して消える |

- 玉が複数になるので `World.balls` の列に。`ball` は代表（乗っている玉があればそれ、無ければ一番下）を返す property で、検査と自動操縦はこれを使う
- 落とすとパワーアップも切れる（バリアも）。自動操縦は玉が上にいる間だけカプセルを拾いに行き（縮むは避ける）、レーザーがあれば撃つ
- タップ（`launch()`）の意味は 1 つずつ：乗っている玉があれば放す → 無ければレーザー → 何も無ければ何もしない

## 演出（2 回目の直しの 2）

- 揺れ：`shake(size, seconds)` で「大きさ」と「いつまで」を持ち、描く側が `sin(time × 90)` でずらす。ふつう 1、爆発 2.5、鉄 0.5、落とす 2
- 残像：玉ごとに直前 6 点を持ち、小さく薄く描く。連続 ×4 で玉が金色、貫通中は橙
- 残り 3 個で点滅、面が変わる間は花火（`pause_until` の間 `burst`）、右上に効いているパワーアップの残り時間の棒

## 仕様

- 板 120 × 84。バー幅 18、玉の半径 1.3。玉の速さは 42 + 面 × 3 + 打ち返し × 0.6（+14 まで）ドット/秒。落とすと玉が 1 つ減り速さが戻る
- 縦の速さは速さの 25% を下回らない（横に走り続けない）
- 連続：バーに戻るまでに壊した数。3 個ごとに倍率 +1（×4 まで。壊した直後の連続数で決まる）
- ベスト：点と到達した面。端末は `records.json`、ブラウザは localStorage
- 音：壁・バー・ブロック・カン・爆発・放す・落とす・面クリア・終了・ベスト

## 入口（ブラウザ）

- 指：`pointermove` で指の x → `world.aim(x)`。バーは 1 秒に 140 ドットで目標を追う（`PADDLE_SPEED`）ので、指が飛んでも滑らかに動く
- 傾き：`deviceorientation` の gamma を ±15° で端まで（g81 と同じ許可の流れ）
- キー：← → は押している間だけ動く（keydown/keyup）

## 検証

- `--check`：面の地図（行の長さ・知らない文字・全種類を使う）、跳ね返り（壁・天井・バーの真ん中は真上・端は 65°・落とす）、ブロック（ふつう・硬い・鉄・爆発の範囲・動く・速い玉もすり抜けない）、連続と倍率、速さの階段、自動で全 8 面（656 秒、落とし 1、拾った 34 個）、玉 3 つでどこまで、パワーアップ 11 種（入れ替わり・時間で切れる・分裂・1 つ残れば落とさない・磁石の角度・貫通・レーザーは一番下を撃ち鉄で止まる・火の玉は上下左右・玉と残機の上限 5・バリアは 1 回）、演出（揺れ・粒・残像）、板の大きさ、記録・音・状態行
- 端末：pty で 26 コマ/秒。矢印キーと a d でバー、スペースで放す
- ブラウザ：Playwright で 29 コマ/秒、エラー無し。自動操縦の狙いをマウスの移動に変えて面 2 まで

## メモ

- 自動操縦は「玉が落ちてくる x を先読みし、残っているブロックの方へ返すよう、その逆側で受ける」。玉 99 個で全面クリアできた
- `remaining() == 0` で面が終わるので、検査で「ブロック無し」の板を作ると次の面に進んでしまう。壊れない鉄や余りを 1 つ置く
- 「同じコマで同じブロックに 2 回当てない」印を列の番号で持っていたら、貫通で消したあと番号がずれた。`id(brick)` で持つ
- 玉の中心がブロックの境目（x = 60）にあると両側の 2 つに当たる。検査の玉は境目を避ける
- レーザーの連射間隔を `time - laser_at < 0.35` で見たら、0.35 を 3 回足した時刻が 1.0499… で撃てなかった。`- 1e-9` を引く

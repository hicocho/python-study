# g73 耳コピ1（音を作る）

流れた旋律を聞いて、鍵盤で同じ音を打ち込む。合っていた音だけが残り、全部そろえばその曲はクリア。
曲は小学校で習う童謡・唱歌のうち、**著作権の切れた 47 曲**。

**ブラウザ版**: https://hicocho.github.io/python-study/g73/

耳コピ 3 段階の 1 つ目（g73 音を作る → g74 音色とリズム → g75 面と採点と記録）。

```bash
python3 main.py            # 遊ぶ
python3 main.py --check    # 決まりを確かめる
python3 main.py --wav 0    # 1 曲目を wav に書き出す
```

音を鳴らすのに `afplay`（macOS）か `aplay`（Linux）を使います。どちらも無ければ絵だけで動きます。

## 今回の主題

**1. 音をデータとして作る — `array` と `wave`**

音は「1 秒に 22050 回、空気の押し引きの強さを数で書き並べたもの」。
`array("h")` は 16 bit の整数がぎっしり並んだ入れ物で、`tobytes()` がそのまま wav の中身になる。

```python
def tone(note: int, seconds: float) -> array:
    count = int(RATE * seconds)
    step = 2 * math.pi * pitch_hz(note) / RATE
    samples = array("h")
    for i in range(count):
        samples.append(int(32767 * VOLUME * shape(i, count) * math.sin(step * i)))
    return samples
```

`shape()` は立ち上がりと消え方。**これが無いと音の変わり目で「プツッ」と鳴る**。
波が途中の高さで急に切れると、そこが「段差」になって聞こえるため。

**2. 出す先を選ばない — `io.BytesIO`**

`wave` はファイルのように書き込む道具だが、`io.BytesIO`（メモリの上のファイル）を渡せば
**bytes が返ってくる**。この bytes を、端末は `afplay` に渡すファイルへ、ブラウザは
`Audio` に渡す data URI へ。**出口が違うだけで、鳴っている wav は同じもの**。

```python
buffer = io.BytesIO()
with wave.open(buffer, "wb") as out:
    out.setnchannels(1)
    out.setsampwidth(2)
    out.setframerate(RATE)
    out.writeframes(samples.tobytes())
return buffer.getvalue()
```

**3. 平均律 — 半音 1 つで 2 の 12 乗根倍**

```python
def pitch_hz(note: int) -> float:
    return 440.0 * 2.0 ** ((note - 9) / 12)
```

この 1 行で 25 鍵ぶんの周波数が全部出る。12 回かければちょうど 2 倍＝ 1 オクターブ上。
`pitch_hz(9)` が 440.00 Hz、`pitch_hz(21)` が 880.00 Hz になることを `--check` が見ている。

## 遊び方

```
 白鍵  z x c v b n m   q w e r t y u i     ← 本物のピアノと同じ並び
 黒鍵   s d   g h j     2 3   5 6 7
       ド レ ミ ファソ ラ シ  ド レ ミ ファソ ラ シ ド

 スペース  お題を聞く（クリアしたら次の曲へ）
 リターン  答え合わせ
 BS        最後に打ち込んだ音を 1 つ消す
 Esc       やめる
```

画面は 128 × 80 ドット。上半分が音の並び、下半分が 25 鍵の鍵盤。

```
  ┌────────────────────────────┐
  │ ─────────────░────────────  │  ░ いま打ち込む場所（縦の帯）
  │ ──■■─────────░───■■──────── │  ■ 青 = 決まった音（もう動かない）
  │ ──────■■─────░─────────■■── │  ■ 橙 = いま打ち込んでいる音
  │ ─────────────█──────────── │  ■ 赤 = さっき違っていた音
  │  ▪  ▪  ▪  ▪  ▪  ▪  ▪  ▪    │  1 列 1 音。色は上のバーと同じ
  ├────────────────────────────┤
  │ █▌█▌ ▌█▌█▌█▌ ▌█▌█▌ ▌█▌█▌█▌ │  25 鍵。**決まった音の鍵は青く塗る**
  └────────────────────────────┘
```

```
  9/47曲目  かえるの合唱  聞いた 2 回  答え合わせ 1 回
  青が 6 音そろった。赤い 1 音をもう一度
  ★★★・★★・★・
```

**1 音目は最初から出ています。** そこからの上がり下がりを当てる遊びなので、
絶対音感は要りません。答え合わせは「合っていたかどうか」しか返しません
（位置も高さも教えない）。

## 仕様

- 音: 22050 Hz / 16 bit / モノラルの正弦波。1 音 0.34 秒、鍵盤を押したときは 0.5 秒
- 鍵盤: 25 鍵（白 15・黒 10）。曲は半音 6 の位置に置く（`OFFSET`）
- 曲: 47 曲。**音の幅がせまい順**に並べてあるので、進むほど難しくなる（幅 3〜12、音の数 7〜15）
- 星: 聞いた回数 3 以下かつ答え合わせ 2 回以下で ★3、6 以下／4 回以下で ★2、それ以外は ★1
- `--check` が見るもの: 音の高さ／wav を書いて読み戻して一致するか／曲集が鍵盤に収まるか／
  25 鍵すべて当たり判定が合うか／答え合わせの決まり／**47 曲すべてが必ず解けるか**

## 曲の選び方（著作権）

日本の保護期間は没後 70 年ですが、**2018 年の延長はその時点でまだ切れていない作品にしか及びません**。
つまり **1967 年以前に亡くなった作曲家の曲は、旧法の 50 年で満了済み**です。この線で選びました。

- 入るもの: 外国の民謡・伝承曲／日本の古謡・わらべうた／1967 年以前に没した作曲家
  （滝廉太郎 1903・納所弁次郎 1936・岡野貞一 1941・田村虎蔵 1943・本居長世 1945・成田為三 1945・
  河村光陽 1946・草川信 1948・弘田龍太郎 1952・中山晋平 1952・梁田貞 1959・佐々木すぐる 1966・**山田耕筰 1965**）
- 外したもの: 井上武士（1974 没）の「チューリップ」「うみ」など

## メモ

- **答え合わせの結果が画面に残らないと、何が起きたのか分からない。** はじめは違った音を
  黙って消していた（青が増えるだけ）。**違った音を赤のまま残し、次に鍵を押したら消える**ようにしたら、
  「どこを直せばいいか」がそのまま見えるようになった
- **決まった音の鍵盤も青く塗る。** 上のバーと下の鍵盤がこれでつながる。
  もう分かっている音なので、これで教えすぎになることもない
- **「いま打ち込む場所」は点ではなく縦の帯にする。** 小さな印だと、どこに入るのか探すことになる
- **「あと ◯ 音」をいつも出す。** 答え合わせを押すべきときが分かる。
  以前は全部そろったときだけ文が出ていたので、押していいのか分からなかった
- **1 音目を見せるかどうかで、遊びが別物になる。** 見せないと絶対音感が要る当てものになり、
  見せると「そこからの上がり下がり」を追う耳コピになる。`start()` の 3 行が遊びの正体
- **合っているかどうか以外を教えない。** 「位置は合っている」まで出すと、耳を使わずに
  推理だけで解けてしまう。耳で確かめれば分かることは、字で書かない
- **ロールの窓の高さは曲によらず固定。** 曲に合わせて伸び縮みさせると、目盛りの間隔が
  「その曲の音の幅」を教えてしまう。位置だけは曲の真ん中に寄せた（せまい曲が鍵盤に張りつくため）
- **`--check` に「必ず解ける」を入れた。** 分からないところを全部同じ音で埋めて答え合わせ、を
  半音の幅ぶん繰り返すと、どの曲も 13 回以内で必ず解ける。詰まないことが機械で確かめられる
- 曲は自分の記憶から書き起こしたので、**1 曲ずつ耳で確かめてから入れた**。
  69 曲書いて 22 曲が間違い（日本の唱歌と、歌い出しが弱起の曲がよく外れた）。残った 47 曲がこれ
- CLI とブラウザで違うのは**入口と出口だけ**。入口は端末のキーか鍵盤のクリック、
  出口は `▀` の並びか canvas、`afplay` か `Audio`。判断（`obey`）も音（`wav_bytes`）も同じ

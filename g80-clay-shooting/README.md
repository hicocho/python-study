# g80 クレー射撃

射撃場に立ち、放出機から飛ぶ皿（クレー）を散弾銃で撃つ。1 ラウンド 25 枚。**3D は g78・g79 と同じく自分で書く。**
g79 の「左右に回るカメラ」を**上下にも**回し、皿の**放物線**、散弾の**円錐の当たり判定**、弾が届く時刻を狙う**先読み**が主題。

**ブラウザ版**: https://hicocho.github.io/python-study/g80/

```bash
python3 main.py            # 遊ぶ（スペースで始める・撃つ。矢印で照準。t で種目。q でやめる）
python3 main.py --check    # 決まりを確かめる
python3 main.py --shot     # 場面を PNG に書き出す
```

ベスト（命中数と点）は `records.json`（この階層。git には入れない）に残る。ブラウザ版は localStorage。

## 遊び方

- 種目：**トラップ**（正面の放出機から遠ざかる向きに飛ぶ）／**スキート**（左右の放出機から交差して飛ぶ）
- 合図（ピッ）の 0.4〜1.3 秒後に放出。矢印（ブラウザは画面をなぞっても）で照準を動かし、スペース（タップ）で撃つ。1 枚に 2 発まで
- 点：粉々 3・割れる 2・かする 1。連続で当てると連続数が出る。25 枚で終わり

## 3D で新しく覚えるところ

### 上下にも回るカメラ

```python
def view(p: V, cam: Camera) -> V:
    q = p - cam.pos
    q = rotate(q, 0.0, -cam.yaw, 0.0)             # yaw は「逆に」回す
    return rotate(q, cam.pitch, 0.0, 0.0)          # pitch は rotate の x 回転の向きが逆なので、そのまま渡すと「逆に」回る
```

順番が大事：**先に yaw、あとで pitch**。逆にすると、右を向いて見上げたときに世界が斜めに傾く。
地平線は pitch で上下する（遠くの点を投影して行を求める）。山と雲は yaw で横に流れる。

### 皿の放物線

```python
def fly(self, dt):
    self.vel = V(self.vel.x, self.vel.y - CLAY_G * dt, self.vel.z).scale(1 - AIR * dt)
    self.pos = self.pos + self.vel.scale(dt)
```

g64 の物理（固定刻み、重力、抵抗）を 3D に。皿は円盤なので揚力で落ちにくい——重力を `CLAY_G = 4.4` にして
本物と同じ 3〜4 秒飛ぶようにした（9.8 だと 1.7 秒で落ちて、狙う暇が無い）。

### 円錐の当たり判定と先読み

```python
def flight_time(shooter, clay):                 # 散弾が皿に届くまでの時間
    t = (clay.pos - shooter).length() / PELLET_SPEED
    for _ in range(2):                           # 届く時刻の皿の位置は動くので、2 回まわして近づける
        t = (clay.ahead(t) - shooter).length() / PELLET_SPEED
    return t

def judge(shooter, aim, clay):
    t = flight_time(shooter, clay)
    target = clay.ahead(t)                       # 弾が届く時刻の皿の位置
    ratio = angle_between(aim, target - shooter) / SPREAD
    if ratio < 0.45: return "smash"              # 粉々（中心に近い＝当たった弾が多い）
    if ratio < 0.8:  return "break"
    if ratio < 1.0:  return "chip"
    return "miss"
```

散弾は円錐に広がる（半角 3.2°、30 m で半径 1.7 m）。**皿の位置が円錐の中か**は、狙った向きと皿への向きの
**角度**を広がりの角度と比べるだけ。距離で広がるのは、角度で比べれば自動的にそうなる。
`ahead(t)` は同じ物理で写しを t 秒進めるだけなので、判定と絵が食い違わない。

横切る皿は弾が届くまでの 83 ms に 1.7 m 動く。今の位置を狙うと「割れる」止まりで、2.5° 先を狙えば粉々（`--check` で確かめている）。

## 直したこと（2 回目：「銃の動きが遅い・合わせづらい」「皿は最初もっと遅く」）

- **照準は押した直後ゆっくり、押し続けると速く**（1.0 → 3.2 rad/s を 0.5 秒で）。細かく合わせるのと大きく振るのを 1 つの操作で
- **1 回押すと 1.7° だけ動く**（4 回目の直し。「ワンクリックの移動幅を小さく」→ 1.1° にしたら遅すぎたので 1.5 倍に）。0.18 秒より長く押し続けたときだけ連続して回る。
  端末はキーの離しが分からないので、OS の連打（繰り返し）が続く間だけ「押している」扱い（0.15 秒で切れる）
- **上下は左右の半分の速さ**（3 回目の直し。皿の上下の動きは小さいので、速いと行き過ぎる）。なぞる操作も同じ
- **皿は最初 13〜16 m/s、15 枚かけて 21〜26 m/s へ**。慣れてから速くなる

- **押せば必ず発砲する**（5 回目の直し。「まれにスペースで発砲されない」）。前は皿が飛んでいないとき（放出前・決着後）は何も起きなかった。
  今は皿が無くても空撃ち（音・反動・「皿はまだ…」「もう割れている」「次の皿を待つ」）、弾が無ければ「カチッ」。皿が出ると弾は 2 発に戻る

- **散弾の広がりを 2 倍（半角 1.6° → 3.2°、30 m で半径 1.7 m）、皿の半径を 0.42 → 0.5 m**（6 回目の直し。「全然当たらない」）。
  横切る皿を今の位置のまま狙っても「割れる」まではいく。粉々には先読みが要る

## 見た目と解像度（7 回目の直し：「背景や皿をもっときれいに、解像度を上げて」）

- **板をブラウザで 5 倍（640 × 400）に。** 端末は 128 × 80 のまま
- **皿**：縁のある円盤（天面・底面・斜めの縁 12 枚）。地面に影を落とす——高さと距離が分かって狙いやすい。破片は板に合わせた大きさ
- **背景**：太陽、雲は明るい上と暗い下の 2 色重ね、山は 3 層（一番奥は淡く）、地平線に林の帯、草に濃い斑
- **木**：針葉樹 4 段・広葉樹 4 つの丸、影つき。放出機に放出口、射台に柵。銃にリブと照星、先台
- **速さ**：山と林は `Screen.strip()`（縦の帯を直接塗る）で描く。`fill()` の 3 倍速い。
  ブラウザは `asyncio.sleep(STEP - 描くのにかかった時間)` に——`sleep(STEP)` だと描く時間ぶん遅れて 20 コマ/秒止まりだった。
  この直しで 640 × 400 でも **29 コマ/秒**。g78・g79 にも同じ直しを入れて 29〜30 コマ/秒に

- **雲が流れる**（8 回目）。雲の向きを `wind`（スタート前から進む時計）× 0.012 rad/s ずらす。雲ごとに速さを少し変えると自然

- **鳥**（9 回目）。1 ラウンドに少なくとも 2 回（何枚目かは `random.sample` で決めておく）＋たまに。左右の遠くから、皿の飛ぶあたりを横切る（翼を羽ばたかせる 2 枚の四角と胴）。
  `fire()` はまず鳥を調べ、円錐に入っていれば破裂（羽が舞う）、**点にならず弾だけ減り**、「鳥は当ててはいけません！」。皿の判定はしない

## 検証

- `--check`：放物線（3.4 秒・最高 6.6 m・66 m 先）、カメラ（30° 見上げて 30° 上の点が正面）、円錐の当たり（0.45／0.8／1.0 倍、届かない距離）、
  先読み（今の位置を狙うと外れ）、自動操縦で 1 ラウンド（トラップ・スキート両方 25 枚全部粉々、0.9 倍ずらせば全部かする、2 倍で 0 点）、
  撃てるとき、板の大きさ、記録、音
- 端末：pty で 30 コマ/秒。スペースで始まり、2 発撃つと「外れ」で次の皿
- ブラウザ：Playwright で 29 コマ/秒（5 倍の板）。種目の選択、スペース・ボタン・タップで撃つ、なぞると照準が動く、エラーなし

## メモ

- **重力 9.8 では皿が 1.7 秒で落ちる。** 揚力のぶん重力を減らした（測って決めた）
- **pitch の符号。** `rotate()` の x 回転は「y を z の方へ」なので、pitch をそのまま渡すと逆回転になる。検査（30° 上の点が正面）で気づいた
- **止まった皿でも 75 ms で 1 cm 落ちる**ので、`flight_time` の検査は誤差 1 ms で比べる
- 皿は小さいので陰影を付けない（`draw_solid(..., flat=True)`）。暗くなると見えなくなる
- 銃身は世界に置かずカメラ座標に直接置く（カメラに付いているので回さない）

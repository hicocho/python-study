# g69 深宇宙シューティング

宇宙船で星雲の中を奥へ進みながら、迫ってくる小惑星を撃つ。60 秒のステージ、体力 3・残機 3。
**中身は Python、絵はブラウザで Three.js**。端末は同じ中身を透視投影の丸と点で描く。

```
python3 main.py            # 遊ぶ（スペースで始める・撃つ。矢印か w a s d で機体。q でやめる）
python3 main.py --check    # 決まりを確かめる
python3 main.py --sheet    # 遊んでいる場面を PNG に書き出す
```

ブラウザ版: https://hicocho.github.io/python-study/g69/

## 主題：中身は 1 つ、絵の出口は 2 つ

- **奥行きのある世界**：物は x（左右）y（上下）z（奥行き）。小惑星は z = 240 に現れて手前へ、弾は奥へ。カメラは機体の少し後ろ上（`camera_at`：機体の位置に 7 割だけ付いていく）
- **透視投影 1 行**：`project()` は `中心 + FOCUS × (物 − カメラ) / 奥行き`。端末の `draw()` はこの式で丸（小惑星）・線（弾）・点（星・粒）を描くだけ
- **球の当たり判定**：弾と小惑星、機体と小惑星は「距離 < 半径の和」。弾は 1 コマに 7 も進むので、奥行きの差は「1 コマで進むぶん」まで許す（すり抜け防止）
- **割れる小惑星**：大 → 中 2 つ → 小 2 つ（左右に ±9 で分かれる）。点は 10 / 20 / 40 で小さいほど高い
- **Three.js（`docs/g69/game.py` の尻尾）**：同じ `World` を毎コマ `sync()` で Mesh に写す。カメラは同じ `camera_at()` の位置、画角も端末の FOCUS から計算。星・霧・光・でこぼこの岩の形は Three.js（GPU）

## Three.js でやっていること（1 回目）

| もの | 作り方 |
|---|---|
| 舞台 | `WebGLRenderer(canvas)`、`Scene`、`PerspectiveCamera(画角, 16:10)`、`FogExp2` |
| 光 | 太陽（`DirectionalLight` 右上手前）、星雲の照り返し（左奥、青）、`AmbientLight` |
| 星 | `Points` 2500 個をカメラに付けて回す。近くの塵 260 個は毎コマ位置を書き換えて手前へ流す |
| 岩 | `IcosahedronGeometry(1, 1)` の頂点を種で決めた量だけ外内へずらす（同じ場所の頂点は同じ量）。6 種類を使い回し、`flatShading` |
| 機体 | 円錐の胴＋箱の翼＋尾翼＋噴射の玉を `Group` に。横へ動くと翼を傾ける |
| 弾 | `CylinderGeometry` を z 向きに、光る色の `MeshBasicMaterial` |
| 粒 | 400 個分の `Points` を用意し、毎コマ `array.set()` でまとめて書く（使わない粒は遠くへ） |

PyScript から呼ぶときの決まり：`THREE.X.new(...)` で作る、引数の dict は `to_js(dict, dict_converter=Object.fromEntries)`、頂点の列は `Float32BufferAttribute.new(to_js(list), 3)`。

## 仕様

- 機体は目標へ 1 秒に 70。枠は ±36 × ±16。指・傾き・キーは全部「目標」を動かす（g68 と同じ）
- 弾は 0.16 秒おき、速さ 220。押している間は連射
- 小惑星は面の表 `STAGES` の間隔（1.1 → 0.5 秒）と速さ（45 → 70）で出る。55% は機体の今いる場所を狙う
- 体当たりで体力 −1、1.6 秒無敵。0 で 1 機失う。3 機で終わり
- 連続 5 発ごとに倍率 +1（×4 まで）。体当たりで 0
- ベスト：点と面。端末は `records.json`、ブラウザは localStorage

## 検証

- `--check`：透視投影（正面は中央・遠いほど小さい・後ろは描かない・端でも板の中）、機体、弾（間隔・消える・連射）、小惑星（割れ方と点・流れる・すり抜けない・同じ種は同じ）、体当たり（無敵・1 機失う・終わり）、連続と倍率、ステージ、自動で 1 面（命中 69・体当たり 1）、板の大きさ、記録・音・状態行
- 端末：pty で 28 コマ/秒。矢印で機体、スペースで撃つ
- ブラウザ：Playwright（SwiftShader の WebGL）で 30 コマ/秒、エラー無し。自動操縦の目標をマウスに変えて 1 面クリア（命中 64/355）

## メモ

- 検査で `world.rocks` を差し替えるときは `next_rock = 999` にして勝手に湧かないようにする
- `CX, CY = ...` のタプル代入は切り出されない（5 回目）。1 行 1 つ
- 自動操縦の命中率は 19%。一番手前を狙うので、割れた直後の小さい石に弾が集まる

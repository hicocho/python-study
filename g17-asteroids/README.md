# g17 小惑星

g16 の宇宙船で、漂ってくる小惑星を弾で砕く CLI シューティングです。
大きい小惑星は撃つと 2 つに割れ、小さいほど速くて高得点。全部砕くと次のウェーブが 1 つ多く来ます。船は 3 機。

g16 → g17 → g18 の 3 段階の連作で、この g17 が「小惑星と弾」、次の g18 が「ランキング」です。

今回の主題は 3 つです。

- **`abc` の抽象クラス** — `Entity(ABC)` が「画面を動くもの」の共通部分を持ち、`@abstractmethod` で「子は必ず `char` を書く」と決める
- **`super().update(dt)`** — 子で処理を足してから親の動きを呼ぶ。g08 の継承の続き
- **`random.gauss` と `random.uniform`** — 「だいたい 6、ばらつき 2」の速さと「0〜2π のどこか」の向き

## 仕様

- 画面は 50 × 22 マス。端はループ（g16 と同じ）
- 小惑星は大きさ 3・2・1（半径 2.4・1.5・0.8）。速さは平均 6 のガウス分布＋小さいほど +2、向きはランダム
- 撃つと 1 つ小さいのが 2 つに割れる。いちばん小さいのは消える。全部消えると次のウェーブ（最初 3 個、1 つずつ増える）
- 弾は 28 マス/秒で 1.2 秒飛んで消える。画面に 4 発まで
- 船に小惑星が当たると 1 機減り、真ん中で復活して 2 秒間は無敵（点滅）
- 弾と小惑星、船と小惑星の当たりは「円と円」：`abs(a.pos - b.pos) < a.radius + b.radius`

## メモ

### `abc` — 「作れない親」を作る

```python
class Entity(ABC):
    def __init__(self, pos, vel, radius): ...
    def update(self, dt): ...
    def hits(self, other): ...

    @property
    @abstractmethod
    def char(self) -> str:
        """画面に出す 1 文字。子が決める。"""
```

`Entity` そのものに意味はありません（「動くもの」一般の位置と速度と半径）。`Entity(...)` と書くと `TypeError` で作れない。
これが `ABC`（抽象基底クラス）で、**`@abstractmethod` の付いたものを子が書かないと、子も作れません**。
「子は必ず `char` を持つ」という約束をコードで守らせる道具です。g08 の `Entity` は普通のクラスで、約束は口頭でした。

### 同じ `update` で全部動く

```python
        for entity in self.asteroids + self.bullets:
            entity.update(dt)
```

`Ship` も `Bullet` も `Asteroid` も `Entity` の `update`（速度ぶん進んで端をループ）を持っています。
子で足したいこと——船は減速、弾は寿命——は子の `update` に書いて、最後に `super().update(dt)` で親の分を呼ぶ。
g08 の「型を聞かずに、呼ぶ」がここでも効いています。

### `hits` は円と円

```python
    def hits(self, other):
        return abs(self.pos - other.pos) < self.radius + other.radius
```

g15 のバンパーと同じ「中心の距離 < 半径の和」。`complex` の引き算と `abs` だけで書けます。
弾と小惑星、船と小惑星、どの組み合わせでも同じ 1 行。

### `split` — 自分から破片を作る

```python
    def split(self):
        if self.size == 1:
            return []
        return [Asteroid(self.pos, self.size - 1) for _ in range(2)]
```

砕けた小惑星は「1 つ小さいのが 2 つ、同じ場所から、ランダムな向きで」。`Asteroid` の `__init__` が速度を作ってくれるので、
`split` は位置と大きさを渡すだけ。いちばん小さいときは空リストを返し、呼ぶ側の `extend` が何もしなくなる——
g10 の「空リストは False」と同じ、**情報を増やしても使い勝手が変わらない**返り値です。

### `random.gauss` — 「だいたい 6」

`random.uniform(4, 8)` は 4〜8 が同じ確率。`random.gauss(6, 2)` は 6 のまわりに集まって、たまに 2 や 10 が出る。
小惑星の速さに `gauss` を使うと「だいたい同じくらいで、たまに速いのがいる」自然なばらつきになります。
`max(2.0, speed)` で遅すぎる（止まっている）ものだけ切り上げ。

### 無敵中は「点滅」で伝える

```python
    if ship.alive and (ship.safe == 0 or int(ship.safe * 8) % 2 == 0):
```

復活直後 2 秒は当たり判定を飛ばします。それを画面で伝えるために、`safe` の残り時間を 8 倍して整数にし、偶数のときだけ描く。
1 秒に 4 回点滅。状態を増やさず、既にある `safe` から導いています。

### ウェーブは `Game` が数える

```python
    def next_wave(self):
        self.wave += 1
        self.asteroids = spawn_asteroids(FIRST_WAVE + self.wave - 1, self.ship.pos)
```

小惑星が空になった瞬間に次を出すので、画面から小惑星が消えることはありません（検証で毎コマ確かめています）。
`spawn_asteroids` は船から 10 マス以上離れた場所にだけ置くので、出た瞬間に当たることもない。

### 自動操縦で難易度を見る

「いちばん近い小惑星を向いて撃つ」だけの自動操縦で、10 回ともウェーブ 4 に到達（平均 6240 点）。
一方、ランダムに操作すると平均 14 秒で 3 機とも壊れます。**狙えば進める、適当だと死ぬ**あたりに置きました。

# g02 じゃんけん

コンピュータと何度でもじゃんけんできる CLI ゲームです。`q` でやめると戦績が出ます。

## ブラウザ版

インストールせずに遊べます → **https://hicocho.github.io/python-study/g02/**

ソースは [`docs/g02/game.py`](../docs/g02/game.py)。判定を行う `judge()` は
CLI 版から 1 文字も変えずにそのまま使っています。違うのは入口と出口だけで、
`input()` の代わりにボタン（キーボードの `g` / `c` / `p` も可）、`print()` の代わりに HTML です。

## 遊び方（ターミナル）

```bash
python3 main.py
```

`g` / `c` / `p` を押して Enter。大文字でも通ります。

```
じゃんけん！
  g … グー
  c … チョキ
  p … パー
  q … やめる

どれにする? (g/c/p/q): g
あなた: グー　コンピュータ: パー
あなたの負け…

どれにする? (g/c/p/q): c
あなた: チョキ　コンピュータ: パー
あなたの勝ち！

どれにする? (g/c/p/q): q

2回勝負 — 1勝 1敗 0分
```

## 仕様

- 入力は `g`（グー）/ `c`（チョキ）/ `p`（パー）、`q` で終了
- 大文字・前後の空白は受け付ける
- それ以外の入力は弾き、戦績には数えない
- 終了時に「n回勝負 — n勝 n敗 n分」を表示
- 一度も勝負せずにやめた場合は専用のメッセージ

## メモ

### 辞書を2つ、別の役割で使っている

| 変数 | 役割 | 例 |
|---|---|---|
| `keys` | 入力キー → 手 の**変換表** | `keys["g"]` → `"グー"` |
| `beats` | その手が倒せる相手＝**ルール表** | `beats["グー"]` → `"チョキ"` |

`beats[you] == cpu` は「あなたの手が倒せる相手がコンピュータの手か？」という意味で、
これだけで勝ち判定が終わります。ルールを `if` で並べる代わりにデータとして持つと、
条件分岐が減ります。

### `judge()` は `print` しない

勝敗を**返す**だけの関数にしてあります。判定（考える）と表示（見せる）が分かれているので、
画面の作りが変わっても `judge()` はそのまま使い回せます。

戻り値の `"win"` / `"lose"` / `"draw"` は `score` 辞書のキーとわざと同じ言葉にしてあり、
集計が `score[result] += 1` の1行で済みます。

### 手の名前を書くのは1箇所だけ

`hands = list(keys.values())` として、`keys` から取り出しています。
同じ情報を2箇所に書くと、片方だけ直し忘れる事故が起きるためです。

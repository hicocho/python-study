# g01 数当てゲーム

コンピュータが 1〜100 からランダムに選んだ数字を、7 回以内に当てる CLI ゲームです。

## 遊び方

```bash
python3 main.py
```

数字を入力して Enter。「もっと大きい」「もっと小さい」のヒントを頼りに範囲を絞り込みます。

```
1〜100の数字を入力（残り7回）: 50
もっと小さい
1〜100の数字を入力（残り6回）: 25
もっと大きい
1〜100の数字を入力（残り5回）: 37
正解！ 3回でした
もう一度？ (y/n): n
またね！
```

## 仕様

- 答えは 1〜100 の整数（両端を含む）
- 挑戦は 7 回まで。使い切ると答えを表示して終了
- 数字以外を入力してもエラーで落ちず、やり直せる
- 1〜100 の範囲外は弾く
- 入力ミス・範囲外は回数に数えない
- 1 ゲーム終了後、`y` で再挑戦、それ以外で終了

## なぜ 7 回なのか

100 個の候補を毎回半分に割っていくと、7 回で必ず 1 つに絞れます（2⁷ = 128 > 100）。
つまり **二分探索を正しく使えば必ず勝てる、ぎりぎりの回数** です。

## メモ

`while` に付けた `else` は、ループが `break` されずに終わったときだけ実行されます。
「当てて `break`」と「回数切れ」がきれいに分岐するので、勝敗判定用のフラグ変数が要りません。

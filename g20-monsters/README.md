# g20 モンスター

g19 のダンジョンに敵を置きました。見えている敵は追ってきて、隣に来ると噛みつきます。体当たりで攻撃。
へびは毒、ねずみは素早く、オークは硬い。体力が尽きたら終わり、地下 5 階の階段でクリアです。

g19 → g20 → g21 の 3 段階の連作の 2 段階目で、ダンジョンの作り方（`Rect` 〜 `make_dungeon`）は g19 と **1 文字も変えていません**。

今回の主題は 3 つです。

- **`enum.Flag`** — 敵の性質を `FAST | ARMORED` のように組み合わせる。`Trait.FAST in traits` で持っているか
- **`random.choices(weights=)`** — 出やすさに重みを付けて種類を選ぶ
- **ブレゼンハムの線** — 2 点の間に壁があるかを調べる `line()`。視界も敵の視線も同じ関数

## 仕様

| 種類 | 記号 | 体力 | 攻撃 | 性質 | 出やすさ |
|---|---|---|---|---|---|
| ねずみ | `r` | 3 | 1 | FAST（1 ターンに 2 歩） | 5 |
| へび | `s` | 4 | 1 | POISONOUS（噛まれると 4 ターン毒） | 3 |
| ゴブリン | `g` | 6 | 2 | なし | 3 |
| オーク | `O` | 10 | 2 | ARMORED（受けるダメージ半分） | 1 |
| トロル | `T` | 12 | 3 | FAST ＋ ARMORED | 1 |

- 自分は体力 20、攻撃 4。5 歩ごとに体力 1 回復（毒の間は回復せず 1 ずつ減る）
- 敵は 1 階に 2〜4 体＋（階 − 1）。最初の部屋には出ない
- 敵は自分が**見えているとき**だけ動く（距離 6 以内で、間に壁が無い）。BFS で最短の 1 歩を進み、隣に来たら噛む
- 視界も同じ判定。壁そのものは見えるが、壁の向こうは見えない
- 記録は直近 3 行を画面の下に出す

## メモ

### `enum.Flag` — 組み合わせられる印

```python
class Trait(Flag):
    NONE = 0
    FAST = auto()
    POISONOUS = auto()
    ARMORED = auto()

    Kind("トロル", "T", 12, 3, Trait.FAST | Trait.ARMORED, 1),
```

g11 の `Enum` は「4 つのうちどれか 1 つ」でした。`Flag` は**いくつでも同時に持てる**印で、`|` で重ね、`in` で持っているかを聞きます。
`Trait.FAST in monster.kind.traits` が `True` なら 2 回動く。トロルは素早くて硬い。
性質が増えても `Kind` の列は 1 つのまま、真偽値のフィールドを性質の数だけ足す必要がありません。`auto()` が 1, 2, 4… のビットを勝手に振ります。

### `random.choices(weights=)` — 重みで選ぶ

```python
            (kind,) = random.choices(KINDS, weights=[k.weight for k in KINDS])
```

`random.choice` は全部同じ確率。`choices` は重みを渡せて、ねずみ 5・オーク 1 なら 5 倍出やすい。
返り値はリスト（何個でも選べる）なので `(kind,)` でほどく。100 階ぶん生成すると、ねずみ 124・オーク 26 でした。

### ブレゼンハムの線 — 2 点の間のマスを順に

```python
def line(a, b):
    ...
    while True:
        yield (x0, y0)
        if (x0, y0) == (x1, y1):
            return
        e2 = 2 * err
        if e2 >= dy:
            err += dy
            x0 += sx
        if e2 <= dx:
            err += dx
            y0 += sy
```

斜めの 2 点の間を「マスの列」として辿る古典的なアルゴリズムです。`yield` で 1 マスずつ流すので（g10）、
`can_see` は途中に壁があった時点で `False` を返して止まれます。g19 では「半径 5 の円」だった視界が、
`visible_cells` の条件を `can_see` に変えるだけで「壁で遮られる視界」になりました。**敵が自分を見る判定も同じ関数**です。

### 敵の 1 歩は BFS の「次の 1 マス」

```python
step = next_step_toward(self.grid, monster.pos, self.player, occupied | {self.player})
```

g12 の `next_step` と同じ考え方で、通れないマス（他の敵）を `blocked` で渡せるようにしました。ゴールの自分のマスだけは例外
（隣まで来て止まるため）。見えていないときは動かないので、壁の向こうから一直線に集まってくることはありません。

### 敵の順番と `break`

FAST は 2 回のループ。「隣なら噛んで終わり」「見えていなければ終わり」「進めなければ終わり」を `break` で抜けるので、
1 ターンに噛む回数は最大 1 回。素早さは移動だけに効きます。

### 「突っ込む」自動プレイで 22/30 クリア

階段へ最短で向かい、隣に敵がいれば殴るだけの自動プレイで、30 回中 22 回が 5 階に到達。体力が減ったら休む版で 24 回。
最初は攻撃 3・回復なしで 4 回しかクリアできなかったので、攻撃 4・5 歩ごとに 1 回復に直しました。
**難しさは自動プレイの勝率で決める**——g13 以来の型です。

# g03 タイピングゲーム

表示された文章をそのまま打ち込む CLI ゲームです。5 問続けて出題し、最後に正解数と
「1 秒あたり何文字打てたか」を表示します。

## ブラウザ版

インストールせずに遊べます → **https://hicocho.github.io/python-study/g03/**

ソースは [`docs/g03/game.py`](../docs/g03/game.py)。集計を行う `summarize()` は
CLI 版から 1 文字も変えずにそのまま使っています。違うのは入口と出口だけで、
`input()` の代わりに入力欄、`print()` の代わりに HTML です。

## 遊び方（ターミナル）

```bash
python3 main.py
```

表示された文章をそのまま打って Enter。前後の空白は無視されます。

```
タイピングゲーム！
表示された文章をそのまま打って Enter。

keep it simple
> keep it simple
OK (3.2秒)

hello world
> helo world
ミス（hello world でした）

...

--- 成績 ---
5問中 4問 正解
速さ: 4.8 文字/秒
```

## 仕様

- 出題は 5 問。順番は毎回シャッフルされる
- 完全一致で正解。1 文字でも違えばミス
- 前後の空白は無視する（`.strip()`）。文中の空白は厳密に見る
- 1 問ごとにかかった秒数を表示
- 最後に「n問中 n問 正解」と「n.n 文字/秒」を表示
- 1 問も正解しなかった場合は速さを出さず、別のメッセージを表示

## メモ

### `for` と `while` の使い分け

g01・g02 は `while True:` で「やめると言われるまで」回していました。今回は出題数が
決まっているので `for` です。

| | 使う場面 | 終わり方 |
|---|---|---|
| `while` | 何回で終わるか分からない | 条件か `break` |
| `for` | 回数が決まっている（リストの数だけ） | 要素が尽きたら自動 |

`for text in texts:` はリストから 1 つずつ取り出すので、終了条件も `break` も要りません。

### `random.shuffle()` は値を返さない

g02 で使った `random.choice()` は選んだ結果を**返す**関数でしたが、`shuffle()` は
リストそのものを並べ替えます。

```python
random.shuffle(texts)          # ○ texts の中身が並び替わる
texts = random.shuffle(texts)  # × None が入って壊れる
```

### 集計済みの数字ではなく、生の記録を貯める

g02 の `score` は `{"win": 2, "lose": 1}` と勝敗の**個数**だけを持っていました。
今回は 1 問ごとに辞書を作り、リストに貯めています。

```python
results.append({"text": text, "ok": ok, "seconds": seconds})
```

平均や「文字/秒」は全問終わらないと計算できません。数えながら捨ててしまうと、
後から別の指標を出したくなったときに元の情報が残らないためです。

### `summarize()` は `print` しない

g02 の `judge()` と同じ約束です。数えるだけして辞書を返し、見せ方は呼んだ側が決めます。
ブラウザ版では `print` の代わりに HTML を組み立てますが、`summarize()` はそのまま使えます。

### 速さは「正解した問題だけ」で計算する

文字数も秒数も、`if r["ok"]:` の中でだけ足しています。ミスした問題の時間まで混ぜると
「1 秒あたり何文字打てたか」が意味を失うためです。

その結果、1 問も正解しないと分母が `0.0` になります。`chars / seconds` は
`ZeroDivisionError` で落ちるので、割り算の前に分岐を置いてあります。
g02 で「一度も勝負しませんでした」を用意したのと同じ、成立しないケースへの備えです。

### 関数の中の `seconds` は外の `seconds` と別物

`for` ループの中にも `summarize()` の中にも `seconds` がありますが、無関係です。
関数の中で作った変数はその関数の中だけで生き、外の同名の変数を書き換えません。

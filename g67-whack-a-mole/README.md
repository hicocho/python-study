# g67 モグラ叩き

穴から顔を出すキャラを叩く。25 秒ずつ 6 ステージ、ステージごとに主役が変わり、穴は 3 × 3 → 4 × 3 → 4 × 4 と増え、最後はふた付き。**14 種**（叩いてはいけないトラップ 4 種を含む）、それぞれ叩き方が違う。
連続で当てるとコンボ（3 回ごとに倍率 +1、×4 まで）。反応時間（顔を出してから叩くまで）を測って平均と最速を出す。

**ブラウザ版**: https://hicocho.github.io/python-study/g67/

```bash
python3 main.py            # 遊ぶ（スペースで始める。穴と同じ並びのキー 7 8 9 / 4 5 6 / 1 2 3、q w e r / a s d f / z x c v で叩く。Esc でやめる）
python3 main.py --check    # 決まりを確かめる
python3 main.py --sheet    # モグラの絵と場面を PNG に
```

ベスト（点・最長コンボ・最速の反応）は `records.json`（git には入れない）に残る。ブラウザ版は localStorage。

## 主題：絵と動きを分ける

前に話した「スプライット（絵）」と「ゲームオブジェクト（動き）」の違いを、そのまま課題にした。

- **絵**は `Sprite`（g32 と同じ。文字で描いたドット絵、`.` が透明）。モグラ・金・ヘルメット・爆弾 × ふつうの顔と叩かれた顔、ハンマー。
  金はふつうのモグラの**色を置き換えただけ**（`recolor`）
- **動き**は `Hole`（穴の状態機械）。`EMPTY → RISING（0.15 秒）→ UP（顔を出す）→ SINKING（0.15 秒）→ EMPTY`、叩けば `HIT`。
  状態と「その状態に入った時刻」だけを持ち、`lift()` が今の高さ（0〜1）を返す
- `draw()` は穴の状態を見て絵を選び、`lift` のぶん上にずらして置く。穴の縁より下は `clip_bottom` で隠す

```python
class State(Enum):
    EMPTY = "empty"; RISING = "rising"; UP = "up"; SINKING = "sinking"; HIT = "hit"

@dataclass
class Hole:
    state: State = State.EMPTY
    kind: str = "normal"
    since: float = 0.0          # いまの状態に入った時刻

    def lift(self, now):        # 0（穴の中）〜1（全部出ている）
        if self.state == State.RISING:  return min(1.0, (now - self.since) / RISE)
        if self.state == State.SINKING: return max(0.0, 1 - (now - self.since) / SINK)
        return 1.0 if self.state in (State.UP, State.HIT) else 0.0
```

## キャラ（2 回目の直し：「モグラ以外にもキャラを増やしたい」）

キャラは表 `KINDS` の 1 行（点・叩く回数・顔を出す時間の倍率・出る重み・動き方・言葉）と絵 2 枚。動き方は 5 種類だけ `Hole` と `World` に手を入れた。

| キャラ | 叩き方 | 点 | 動き方 |
|---|---|---|---|
| モグラ | 1 回 | +1 | |
| 金 | 1 回。時間 0.6 倍 | +5 | |
| ヘルメット | 2 回（1 回目でひび） | +3 | |
| 爆弾 | 叩くと減点・コンボ 0 | −3 | |
| スライム | 1 回目で**隣の穴へ跳ねる**、2 回目で倒す | +2 | `hop` |
| メタルスライム | 3 回。時間 0.45 倍、めったに出ない | +10 | |
| おばけ | 0.3 秒ごとに**見え隠れ**。消えている間は空振り | +4 | `blink` |
| ウサギ | 0.4 秒ごとに**別の穴へ跳ぶ**（3 回で逃げる） | +3 | `jump` |
| ネズミ | **3 匹同時**。全部叩くと +6 | +1 × 3 | `swarm` |
| 砂時計 | 叩くと**残り時間 +3 秒**。後半ほど出やすい | 0 | `time` |
| 王様 | ステージ 5・6 に 1 回ずつ出る。**4 回**。倒すとコンボ +3 | +15 | ステージの `king_at` 秒で出す |
| ハチの巣 | 叩くと**ハチが 3 秒飛び回り、その間の点は半分** | 0 | `trap` |
| サボテン | 叩くと**ハンマーが 1.5 秒しびれて叩けない**（空振りにもならない） | 0 | `trap` |
| カメ | 叩くと**甲羅にこもって 4 秒穴をふさぐ**。甲羅を叩いても罰は無い | 0 | `trap`（`State.SHELL`） |

- スライムの跳ねは「この穴を空にして、隣の空いた穴に同じスライム（残り回数を引き継ぐ）を出す」。ウサギの跳びも同じ作り（出した時刻を引き継ぐので反応時間が正しい）
- おばけは `visible(now)`：`UP` の間 `int((now − since) / 0.3) % 2 == 0` のときだけ見える。`whackable(now)` がそれを見る
- ネズミは `pop()` が 3 つの空いた穴に同じ群れ番号で出す。`swarms[番号] = [叩いた数, 逃した数]`
- 砂時計は `extra` に足し、そのステージの残り `stage_left()` が延びる（1 ステージ 9 秒まで）
- 王様は重み 0（抽選しない）。ステージの `king_at` 秒を過ぎた最初の放出で出る
- トラップ（3 回目の直し）：罰の種類を「点（爆弾）」「点が半分（ハチ）」「時間（サボテン）」「場所（カメ）」でばらけさせた。
  ハチは `bees_until`、しびれは `numb_until`、カメは穴の状態 `SHELL`（`pop()` は EMPTY の穴にしか出さないので自然にふさがる）

## ステージ（4 回目の直し：「ステージアップしても飽きないように」）

| # | 名前 | 穴 | 主役 |
|---|---|---|---|
| 1 | モグラの野原 | 3×3 | ふつう 70・金・ヘルメット |
| 2 | スライムの沼 | 3×3 | スライム 36・メタル・サボテン |
| 3 | おばけ屋敷 | 3×3 | おばけ 30・ネズミ 20・ハチの巣 |
| 4 | トラップ畑 | 4×3 | 爆弾・ハチの巣・サボテン・カメ で半分 |
| 5 | 動物園 | 4×4 | ウサギ 26・カメ・ネズミ、10 秒目に王様 |
| 6 | ごちゃまぜ | 4×4 | 全部（表の重みそのまま）、12 秒目に王様、**穴にふた** |

- `STAGES` は 1 ステージ 1 行の表（名前・穴の数・重み・王様の時刻・ふた・草の色）。ステージが変わるのは `update()` の先頭で、
  `holes` を作り直して 2.5 秒の間を置く（その間は `pause_until` で何も出さない）
- 穴の数が変わるので、`hole_rect(index, cols, rows)` と `cell_size()` が板を割り付け、ブラウザのタップと端末のキー `keypad(cols, rows)` は同じ割り付けを読む。
  キーは穴と同じ形に並べる（`KEYMAPS`：3×3 は `789/456/123` と `qwe/asd/zxc`、4×3 は `qwer/asdf/zxcv`、4×4 は `1234/qwer/asdf/zxcv`）。
  q と r がキーになったので、やめるは Esc、もう一度はスペース
- ふた：`Hole.lid_open(now)` が 2.4 秒周期のうち 1.4 秒だけ真。穴ごとに位相をずらす。閉じている間は `visible()` が偽 → 叩くと空振り、描く側は板を描く
- 草の色もステージの表から。板は 4 行のとき穴の高さを 22 → 16 に

## 仕様

- 25 秒 × 6 ステージ（間 2.5 秒）。出る間隔は `1.3 → 0.45 秒`、顔を出す時間は `1.5 → 0.7 秒`（全体の時間の式。難しさの階段）。金は 0.6 倍の時間
- 種類は `random.choices(weights=)`：ステージの表の重み（無いキャラは出ない）。6 ステージ目は `KINDS` の重みそのまま
- 空の穴を叩くと −1、爆弾は −3、どちらもコンボが 0 に。ヘルメットは 1 回目「クランク」、2 回目で割れる
- 点 = 種類の点 × 倍率（`min(4, 1 + 連続 // 3)`）
- 音：出た・叩いた・金・クランク・跳ねた・チクタク・王様・爆弾・空振り・ステージ・終了・ベスト

## 検証

- `--check`：絵（14 種 × 2）、トラップ（点が半分・叩けない・穴をふさぐ）、状態機械の遷移、叩く（空振り／ふつう／金／爆弾／おばけ／ウサギ／ヘルメット 2 回、反応時間）、
  新しいキャラ（跳ねる・3 回・見え隠れ・跳ぶ・群れ・砂時計・王様）、コンボ、難しさの階段、自動で叩いて 1 ゲーム（285 回、命中 214、1967 点、ステージ 5 回変わる）、
  ステージと穴の形（穴は板の中・キーと穴は 1 対 1・ふたの開く割合・閉じている間は空振り）、板の大きさ、記録、音
- 端末：pty で 28 コマ/秒。数字キーで叩ける、Esc で終わる
- ブラウザ：Playwright で 29 コマ/秒。叩ける穴と穴の形を見てタップとキーで 6 ステージ全部叩き、命中 212・空振り 0・1633 点

## メモ

- 端末の状態行は 120 桁に収める（最初 137 桁あった）
- コンボの倍率は「叩いた直後の連続数」で決まる。検査で 1 つずれていた
- 状態行は `columns()`（`unicodedata.east_asian_width`）で表示幅を測り、知らせを切って 120 桁ちょうどに
- 砂時計を自動で全部叩くと 1 ゲームが 220 秒に延びたので、延びるのは 1 ステージ 9 秒まで
